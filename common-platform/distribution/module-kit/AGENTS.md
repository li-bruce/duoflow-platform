# 模块套件维护

先阅读 README、COMPATIBILITY.md、docs/ARCHITECTURE.md 与 Skill。协议与抽取的验证器来自配套平台；修改后完成两侧语义和负例验证，不仅更新来源散列。SDK、模板、技能、文档和测试一同维护。

依赖安装到本仓库 .venv 和 node_modules。生成物、数据库、日志和临时输出放忽略的 work，测试使用独立目录。不要提交凭据、个人图布局、运行记录或依赖目录。

按已确认业务维护 business-observer；保存实际来源和未验证范围。源码保持可读，主要函数说明目的及边界；格式调整核对行为等价。执行 unittest、生成模板独立测试和页面实际交互检查。交付中文规范 Git 提交；仅在用户授权时上传。
