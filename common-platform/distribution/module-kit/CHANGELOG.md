# 发布记录

## v0.02

- 增加 module-graph、flow-exports、runtime-observation 及 composition 公共契约。
- 模块逐项登记前后端原子、输入输出、事件、局部状态和业务节点关系。
- 同一模块可公开多个完整/部分业务流，声明数据操作、权限和正式完成条件。
- 新模板使用 registration 1.1，实际函数绑定、运行回调及主动挑战全部通过后接入。
- Python/Node SDK 提供有界观察队列、原子结果和真实状态变化检查工具。
- duoflow-module Skill 维护原子、公开节点、业务流到完整 Observer 模型的映射。
- 通过两个真实服务的完整 Observer 联合检查，补充源码清单、组件交互、参数采集与架构归属说明。
- 更新独立文档、源码地图、介绍页和分步演示；旧模板及 1.0 接入保持兼容。

## v0.01

- 独立发布协议、SDK、Python 原生工具与 Node 流程模板。
- 提供无需运行主平台的模块生成、输入输出和声明检查。
- 新增 duoflow-module Skill、Observer 固定来源校验、支持文件安装和业务映射检查。
- 联合门禁调用模块检查、需求确认、源码同步及架构检查。
- 联合检查确认模块映射与同步验收使用同一组业务材料，并覆盖缺失、错配和项目模型变化的拒绝场景。
- 对齐持续同步命令及远程模块的注册声明、握手和七项接入检查说明。
- 增加源码导读、版本对应、独立介绍页和分步交互演示。

跨模块通用执行器、生产多角色业务和真实模型调用留待专项研发与验收。多语言源码适配使用固定 Observer 版本，项目动态行为需要实际接线验证。
