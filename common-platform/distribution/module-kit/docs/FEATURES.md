# 功能和支持范围

| 特性 | v0.02 提供内容 | 验证方式 |
| --- | --- | --- |
| 独立生成 | Python 原生工具、Node 远程流程 | 在干净目录生成并运行模板测试 |
| 业务对象与动作 | 公开数据结构、查询和命令、职责/范围、状态与修订 | 静态引用检查及业务正反例 |
| 页面与对话 | 相同组件绑定相同能力和正式对象 | 安装后两种入口办理同一事项 |
| 原子组件 | 输入输出、事件、状态、业务节点和调用关系 | 实际函数/组件绑定、Schema 和关系检查 |
| 公开业务流 | 完整流程、部分流程或单项功能；权限和数据边界 | 入口、版本、完成状态、对象读取检查 |
| 接入握手 | registration 1.1、真实函数绑定和主动回调；保留 1.0 兼容 | 平台实际接收挑战、完整检查和显式发布 |
| 运行同步 | 真实调用与状态事件、组件实例及前后关系 | 重复、乱序、缺失、撤权和观察故障检查 |
| 状态测试 | SDK 对照真实前后状态与原子结果 | 模块独立测试及平台实测 |
| 业务建模 | 固定版本 business-observer、开发 Skill | 来源校验、需求记录、业务网与预期 |
| 持续同步 | 能力、状态、原子、节点及公开流程到完整模型的映射 | mapping 与 gate；独立业务证据 |
| 阅读与展示 | 目录说明、关键函数注释、介绍页、独立演示 | 源码审阅与实际浏览器操作 |

静态模块检查不执行待检查模块的函数，解析前端使用本仓库 TypeScript。Observer 的结构映射不等于业务正确；联合 gate 还要求真实源码同步与项目检查。模块服务关闭观测后仍由其业务代码决定结果。

已有 Python 远程工作流可按相同协议适配，当前生成器提供上述两个模板。Observer 提供 Python、JS/TS、React、Vue 源码适配，所需解析器独立安装。配套平台支持顺序组合与明确字段连接；通用分支、并行、循环和自动补偿仍需另外实现。介绍页中的动画使用本地演示数据。
