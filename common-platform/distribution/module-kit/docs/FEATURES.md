# 功能和支持范围

| 特性 | v0.01 提供内容 | 验证方式 |
| --- | --- | --- |
| 独立生成 | Python 原生工具、Node 远程流程 | 在干净目录生成并运行模板测试 |
| 业务对象与动作 | 公开数据结构、查询和命令、职责/范围、状态与修订 | 静态引用检查及业务正反例 |
| 页面与对话 | 相同组件绑定相同能力和正式对象 | 安装后两种入口办理同一事项 |
| 接入握手 | registration 1.0 与真实函数绑定确认 | 平台七项检查和显式发布 |
| 业务建模 | 固定版本 business-observer、开发 Skill | 来源校验、需求记录、业务网与预期 |
| 持续同步 | 公开能力/状态到模型的映射、上游检查入口 | mapping 与 gate；独立业务证据 |
| 阅读与展示 | 目录说明、关键函数注释、介绍页、独立演示 | 源码审阅与实际浏览器操作 |

静态模块检查不执行待检查模块的函数，解析前端使用本仓库 TypeScript。Observer 的结构映射不等于业务正确；联合 gate 还要求真实源码同步与项目检查。模块服务关闭观测后仍由其业务代码决定结果。

已有 Python 远程工作流可按相同协议适配，当前生成器提供上述两个模板。Observer 提供 Python、JS/TS、React、Vue 源码适配，所需解析器独立安装。生产身份提供方、游客、自助注册、跨服务事务及任意流程自动组合不属于本版已实现能力。介绍页中的动画使用本地演示数据。
