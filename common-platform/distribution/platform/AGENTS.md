# DuoFlow Platform 维护

本仓库是独立主框架。保留 common-platform 目录；进入后遵守其 AGENTS。先阅读 README、源码阅读指南、主框架说明及最新 prompts/_source。实际校验器和真实执行是能力依据。

运行数据、配置、依赖和测试输出各自隔离；临时目录使用本根 work。修改公开协议时同步模块套件、SDK、模板和负例测试；更新提示词源并执行生成器 --write --reviewed、--check。呈现或宿主变化须构建后完成真实浏览器办理与恢复验证。

源码保持常规格式，主要方法说明输入、状态/权限边界及效果。业务状态、私人导航和 Run 状态分别维护；中立示例的限定规则不推广到其他业务。发布记录与实际检查范围一同保留。用户明确授权后才上传远端。
