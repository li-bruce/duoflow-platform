# 通用模块生命周期与两端入口

管理员在本平台配置远程服务地址与私有连接凭据，发现 manifest 时保持禁用。检查能力与版本后，安装受信任的 interaction/workflow 前端包并生产构建，注册模块的 access v1 定义，再启用服务并给用户授予准确范围的职责。安装定义不会自动授权用户。

平台校验页面工具覆盖全部能力，对话声明同样覆盖全部能力；同一共享 React 组件与对象 adapter 用于两端。流程和组件源码安装、构建、后端可用、当前用户授权是不同条件。新增流程不会因仅复制文件而自动加载，需要重启平台并重新核验。

远程 manifest 可声明 `embedded` 页面工具，其 path 只能是同服务绝对路径，不能包含 URL、查询或跳转片段。平台通过 `credentialless` iframe 与 `sandbox="allow-scripts allow-forms"` 隔离页面，不传递平台登录凭据或服务 Bearer；不支持隔离的浏览器会拒绝加载。已有页面依赖平台 Cookie、同源权限或 SSO 时，必须另行适配，不能把 iframe 当成统一登录。

禁用、离线或撤权后，旧入口与实例也必须重新检查。个人 cursor/草稿/对话属于平台，正式对象和业务状态属于模块仓库。分支复制个人视图和对象引用，不重放正式写入，也不回滚数据库。

继续阅读 [模块开发与调试说明书](模块开发与调试说明书.md)、[模块模板使用手册](模块模板使用手册.md) 和 [远程协议](remote-service-protocol.md)。本中性 framework-lab 验证共享宿主和状态机，不代表真实多角色审批业务已上线。
