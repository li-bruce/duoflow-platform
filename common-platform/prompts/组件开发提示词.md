## 交付结构与接入

交付 `component/Component.tsx`、`component/interaction.json`、后端业务能力、测试、启动说明、`PLATFORM_BOUNDARY.md` 和 `DEVELOPMENT_INPUT.md`。模块源码纳入独立本地 Git；验证后以中文规范 commit 提交，不推送，不提交密钥、运行数据或依赖。

前端统一 React 19 / TypeScript。`Component.tsx` 默认导出业务组件，通过 `@platform/interaction-sdk` 导入 `InteractionProps`。组件接收 input、state、result、surface、busy、actions、updateState 和 invokeAction；不得直接调用业务服务 URL、读取平台 Cookie/Key 或维护聊天历史。

安装到 `components/packs/` 的 TypeScript 文件纳入平台类型检查；React、React DOM 及 JSX runtime 统一使用宿主前端依赖。不要在组件包中另装 React 或复制宿主 SDK。独立开发环境可声明这些 peer dependencies；实际接入以平台 `web` 的类型检查和生产构建为准。组件 CSS 与公开源码一起纳入提示词一致性检查。

调用 `updateState` 时提供完整状态对象。宿主会串行保存、显示保存状态，并在提交动作前保存最后修改。网络错误或修订冲突时保留本窗口内容并停止继续保存；“重新读取”会丢弃本窗口未保存编辑。结果以服务返回为准；busy 时禁用业务编辑和执行。动作不可用时禁用相应按钮。

将组件目录复制到平台 `components/packs/<pack>/`，在 `components/installed.json` 的 packs 数组追加目录名，保留已有条目。目录名为小写字母起始，仅字母、数字和连字符。前端构建时发现组件，服务端启动时读取安装清单。安装/升级需要重新构建前端并重启平台；当前没有动态下载远程 JavaScript 的插件商店。

Python local：将后端复制到 `extensions/<module>/` 并追加 extensions 安装清单。handler 接收 ctx 和 payload，返回 CapabilityOutput；ctx.actor 为平台认证身份，ctx.access 提供中央范围判断，ctx.access_stamp 是受控调用的授权快照。注册权限模块先用自有仓储 facts 调用 `ctx.access.check` 再执行状态机；ctx.create_resource 会携带快照。平台统一管理事务，不要自行 commit。

Node.js remote：独立进程，提供 GET `/platform/v1/manifest`、GET `/platform/v1/health`、POST `/platform/v1/invoke`。使用 manifest 1.2 / invoke 1.1，三个端点均验证私有 Bearer 凭据。未注册 access 的旧模块保留固定角色守卫；注册范围权限的模块使用下述 X-Platform-Access 决策桥接，再检查对象和状态，不在失败时退回旧角色允许。管理员发现并启用服务后，组件 actions 引用注册的能力 ID 和版本。组件开发不需要将 Node 代码变成 Python。

Python 同步动作直接返回结果。当前远程协议采用 background：组件动作提交后进入平台队列，宿主轮询运行状态并呈现成功、失败、重试或停止等待。执行期间服务端拒绝编辑；远端停止与本地取消不同，取消不能保证远端副作用未发生。不得把 queued 状态显示为已完成。

两种后端示例具有相同 ID，仅用于二选一。需要同时接入时改成两套唯一 ID，并分别注册组件动作绑定。Node 服务的 npm 依赖独立于平台前端依赖；新增浏览器依赖需显式交付依赖清单，并由平台锁定安装。

## 组件定义规则

interaction.json 遵循附录 Schema。它独立于微服务 manifest；不增加旧协议字段。

- input_schema 与 state_schema 均为对象 Schema，仅使用本地片段引用。initial_state 符合 state_schema。
- id、version、title、description 描述组件。triggers 是可选的完整入口语句；精确匹配无需模型，也可输入 `/component <id>`。
- actions 是具名动作。capability_id 和 capability_version 绑定已注册能力；bindings 将组件 input 或 state 的顶层字段映射到能力输入字段。当前不支持嵌套表达式、任意脚本或浏览器指定目标能力。
- 一个组件可调用多个能力，也可引用不同模块的能力；它们的角色、版本和参数都必须通过平台核验。这不等于已实现任意跨角色 DAG 编排。
- completes 表示该动作成功后当前组件阶段完成。异步任务成功前不可完成。修改状态后此前结果清空，历史能力调用仍保留。
- 每个输入对象和状态对象最多 64 KB；不保存 content_base64 文件字节和已配置凭据。业务大对象以受控引用表示。

## 多步骤工作台：共享步骤与业务对象

有独立业务对象、跨角色办理或长任务时，采用 `@platform/workflow-sdk`，而非把整个网站放入单组件 state。提供 `flow.json` 和 `steps.tsx`；后者导出 `stepComponents`，每个组件接收 `WorkflowStepProps`。固定页面通过步骤导航组织相同组件，对话只渲染当前步骤并显示文字引导。两处共用 React 源码；表单字段、角色决策、校验规则和业务状态名均由模块拥有，不写入通用核心。

安装目录为 `flows/packs/<pack>/`，清单为 `flows/installed.json` 的 packs。使用附录 `contracts/workflows/v1/definition.schema.json`，与旧 interaction 定义、远程 manifest 分开。一个包可有多个 flow；步骤必须具备 id、title、description、component、actions；initial_step 和 target_step 引用真实步骤。每步可声明完整 triggers。`/flow <id>` 打开个人流程，当前对话的 `/step <step_id>` 或精确步骤触发语只切换导航。自由表达通过主平台模型选择打开或切步工具；模型不能据此自动确认、批准、发布或修改业务状态。

固定页面可声明 page_groups，每组有 id、title、steps，引用已注册的步骤；宿主同时渲染该区域的多个组件。对话继续只渲染当前步骤。每个组件保留按 step id 分开的个人草稿；非当前组件的动作先通过正常 PATCH 保存草稿并移动游标，再调用既有 action 接口，不绕过服务端守卫。实例响应 actions/step_actions 是按当前身份和业务状态计算的动作摘要，完整 command_schema 留在静态 catalog。未声明 page_groups 时固定页保持单步导航。 宿主按实例隔离异步读取，拒绝旧响应及修订倒退；重新读取时锁定编辑并等待已发出的保存结束。目录和详情同样丢弃失效请求。页面和对话宿主空闲时约每 15 秒复核可见性；403/404 或流程定义变化清除失权内容，普通网络失败保留私人草稿。轮询是界面更新机制，不能替代服务器每次请求的授权判断。

provider 固定声明 object_type、read_capability，以及需要时的 upload_capability、jobs_capability。前端不提交 provider、URL、身份或 object_ref。读取能力决定谁能打开流程，各动作再分别按能力角色、可用性、版本和业务 projection.allowed_actions 投影；不能要求提交者同时拥有审核权限。流程中的创造对象动作按其能力授权，与当前所选对象能否修改分开。

action 的 id 只用于选择已安装定义，capability_id/version 由服务端固定绑定。默认动作发出 `{object_id, expected_revision, command}`；creates_object 动作只有 `{command}`。command 必须符合声明的 command_schema 和后端能力输入 Schema。可选 `mode: "draft_query"` 仅限 sync query：只发送 `{command}`，不能同时 creates_object，不传正式对象引用，也不改变正式业务状态。它适合显式合成样例比较或模型草案建议；返回值不能冒充正式校验、审批或发布凭证。

必须区分四类状态：模块持有正式业务对象和不可变内容版本；任务执行者持有任务状态与进度；宿主持有每个用户的未提交草稿；个人流程持有当前步骤游标。平台 WorkflowInstance 仅保存 object_ref、drafts、cursor、修订和命令回执引用，不作为业务状态镜像。每次恢复从服务读取当前 projection，并重新计算允许动作。提交和审核必须在模块内按当前角色、对象范围、expected_revision 和状态机再次判断；游标切到某一步不等于取得该步权限。

跨角色交接通过授权业务对象/待办：接手者用自己的流程实例读取同一对象，不复制他人的对话或个人草稿。页面与对话继续同一个个人实例时共享草稿；同对象的其他个人流程使用各自草稿，但共读业务权威状态。分支只复制当前已保存草稿、游标及对象引用，不复制运行中的任务，不回滚业务，不重放任何命令。恢复、切步、创建分支都不是审批事件。定义或授权修订变化后旧个人流程被拒绝，尚无任意版本状态迁移。

SDK 的 updateDraft 提交当前步骤完整草稿，宿主按步骤键保存总计最多 64 KB；execute 先保存草稿，再带个人修订和业务修订执行命令。成功回执与个人执行引用在平台同一事务保存；业务服务仍必须把命令回执与业务修订放在自身同一事务。网络重试保留原请求编号和内容，target_step 成功切换后原请求仍应可安全重读。直接读取不会重放命令；正式动作以实际成功结果为准。

平台 Run 失败后，步骤宿主的“重试原请求”继续同一 Run 和 invocation，使用原始输入；后续修改的个人草稿不会替换该请求。业务 job 的失败与重试仍由模块能力单独实现，不能把重试平台启动请求当作重做整个业务 job。

API 前缀 `/api/v1/flows`：GET `/catalog`、GET/POST `/instances`、GET/PATCH `/instances/{id}`、POST `/instances/{id}/select`、POST `/instances/{id}/actions/{action}`、POST `/instances/{id}/attach`。PATCH 接收 cursor、drafts、expected_revision；select 接收 object_id、expected_revision，空 object_id 只清除当前个人对象引用与草稿，不删除业务对象；action 接收 command、expected_revision、expected_object_revision、idempotency_key。写入均用已有登录会话与 CSRF。

## 文件与长任务适配

文件传输和长任务使用独立 workflow adapter v1，不扩充原 invoke 外壳。小文件 `platform-file` 的单文件 4 MiB 限额保持不变。大文件由上传会话分块传输，正式对象保存 file_ref，不把 base64、文件内容或凭据塞进草稿/消息/模型。浏览器按最多 1 MiB 的片段计算摘要和上传，实际限额由业务存储适配器控制。支持分块不等于已验证任意 GB 容量，必须分别记录小样例与容量试验。

远端固定接口为 POST `/platform/v1/workflow/{operation}`；允许 objects.list/read、uploads.create/status/complete/abort、jobs.status/result/cancel，分块使用独立 PUT 路径。包络、file_ref、upload 与 job 的精确字段在附录。平台仅从管理员现有连接获取 Bearer，注入可信 actor 和绑定 object_ref，执行前后检查授权和连接修订；模块再次检查机构、所有者、对象、upload/job/file 的真实关联。知道编号不等于可访问文件。

大结果必须在模块内持久保存，objects.read、业务命令、上传和 job 结果只返回有界摘要，不重复内联全部明细。objects.list 接收 object_type、可选 cursor 和 limit（1—50），返回 objects 与 next_cursor；只可请求 provider.object_type 或显式 related_object_types（最多5类）。objects.detail 接收绑定 object_ref、模块声明的 section、cursor、limit，返回 object_ref、revision、items、next_cursor、total。详情章节由模块白名单裁决；游标不是授权，逐次核验身份、对象及修订。超长单值的裁剪必须明示，不能伪装完整内容。列表响应上限128 KiB、对象投影1 MiB、详情512 KiB，最终合并的个人 Flow 响应仍限2 MiB。不得通过提高全局上限来容纳不断增长的报告或版本历史。

宿主 SDK 的 detailPage(section,cursor?,limit?) 和 loadMoreObjects(objectType) 使用同源 POST `/instances/{id}/detail`、`/instances/{id}/objects/list`。objectPages 提供各授权类型的目录游标。分页内容只保存在当前视图内存，不进入个人草稿或模型上下文；切换对象、业务修订或章节后废弃旧页和未完成响应。恢复按当前状态重新读取，不用旧页替代业务记录。

平台同源 API 位于 `/api/v1/flows/instances/{id}`：POST `/uploads`，GET `/uploads/{upload_id}`，PUT `/uploads/{upload_id}/chunks/{index}`，POST `/uploads/{upload_id}/complete|abort`，GET `/jobs/{job_id}`、GET `/jobs/{job_id}/result`、POST `/jobs/{job_id}/cancel`。create 上传必须有稳定 idempotency_key；complete、abort、cancel 带 expected_revision。断点恢复需重新选择同一个文件，校验长度和 SHA-256；服务验证分块和完整摘要后原子关联，明确失败清理、孤立文件和恢复策略。

任务 start 由已登记业务能力实现，并返回 job_ref；平台调用成功只表示启动命令完成，任务结果必须从业务 job 状态取得。取消只有执行者确认尚未提交且停止后才是 cancelled，提交点后应拒绝取消；HTTP 超时或停止本地等待不证明远端停止。声明并验证进度、失败、手动重试、重启恢复和不重放。适配器不自带调度器、跨服务事务、Temporal 或任意副作用“恰好一次”保证。

Python 也可以作为正式业务对象的所有者。受控 local 模块在 manifest 顶层声明 `workflow_adapter: "adapter:create"`；工厂只能引用包内简单文件名与函数名。factory(context) 接收不可变 LocalWorkflowContext，其字段为 sessions、模块专属 data_dir、module_id；不包含请求身份、runtime 或模型网关。返回对象实现 `request(*,actor,capability_id,operation,payload,request_id)`，可选 `upload_chunk` 的精确参数见模板/传输接口。平台逐次注入已授权 actor，adapter 返回与 HTTP data 相同形状；handler 负责业务写入，adapter 提供同源的授权 read/list、文件或任务操作。Python 示例中某个能力只比较样例，是模块选择，不是框架对 Python 的限制。未实现的文件/任务方法返回 501；框架没有自动替每个 Python 模块提供大文件存储。

需要模型提炼规则时，先生成可读且受限的 DSL 草案，严格验证操作白名单和参数，再用合成样例试跑与差异对照，由独立人工审批发布不可变规则版本。运行时执行确定性规则，不执行模型生成的 Python/JavaScript、任意表达式或正则。模型失败、无效结构和超时必须保留为真实失败；“模型已建议”不代表“规则已发布”。 本地 ctx.gateway.chat 可返回白名单 finish_reason（stop、length、max_tokens、tool_calls、content_filter、function_call），仅在供应商实际返回受支持值时保留；缺失不能推断完成。模块可在既有安全错误详情中分类空内容、截断、JSON 或 DSL 不合格，不能写入原始模型回复和凭据；提示中的输出根结构须与校验 Schema 一致。

## 身份、恢复与分支

开发多职责业务时，先给出角色职责、动作权限、对象范围、状态条件、字段投影和 Web/对话步骤矩阵。共享正式对象和业务状态机；提交、处理、审核等职责可以组织不同办理路径，共用证据或编辑组件，专有任务使用专有组件。组件的隐藏、只读和禁用只是呈现，真实数据投影与动作授权必须在服务端执行。列表、数量、附件、模型上下文和历史结果同样需要权限判断。

当前已支持独立 `contracts/access/v1` 权限包：local 模块交付 `access-definition.json` 由受控安装加载；remote 在发现后通过主框架管理入口注册相同附件。远程顺序为发现并保持禁用、安装需要的 flow/组件、注册附件、启用、再授权；启用但尚无 grant 的新模块拒绝访问。包中声明 permissions、role_templates、scope_keys、command_mappings、experiences、workitem_sources 等严格字段，完整格式见附录。不向现有 manifest、flow 或 actor 私加角色和权限。权限、角色模板、办理视图和待办源都使用本模块命名空间。安装只注册定义，不授予用户权限。实际授权由有 identity.manage 的管理者按单个用户和完整 scope 分配；尚无组授权、委托管理员或外部 OIDC 登录。

同一授权内的项目/机构/owner 等条件同时满足，不同授权之间不能拼接条件。旧授权保留原权限快照，升级新增权限须重新授予；收紧和撤销生效。actor_is_fact、actor_not_fact 和 fact_in 守卫使用模块仓库事实，缺失默认拒绝。Casbin 模型由框架固定，模块不提供任意执行表达式。使用 ctx.access.check 作实际对象授权；has_permission 只供目录，matching_scopes 返回完整 OR-of-AND 范围。列表、数量、字段和下载先授权再输出。模块仍负责业务状态机、并发修订和幂等。

experiences 按 required_permissions 映射已安装 flow_id，可选 step_ids 限定可见步骤，宿主同时过滤 Web page_groups 和对话步骤。多个获准 experience 的步骤可合并；这不增加动作权限。已注册模块没有匹配 experience 即拒绝打开，不能退回旧角色。不同职责可组织独立 flow 并复用组件；同一人跨项目兼任职责时，给不同路径绑定各自 read capability，让服务器端目录和单对象读取落实职责范围。前端隐藏和只读仅为呈现。

统一“我的业务”API：GET `/api/v1/business/catalog` 查询办理入口，GET `/api/v1/business/instances` 返回本人最近最多 100 个可恢复流程，GET `/api/v1/business/objects?flow_id=...` 经授权 provider 实时读取目录，POST `/api/v1/business/open` 以 instance_id 恢复本人流程，或以 flow_id、可选 object_id、idempotency_key 建立工作台；surface 可选 page/conversation。要延续私人草稿，应传原 instance_id；仅有同一业务 object_id 不代表使用同一个私人实例。workitem_sources 是注册元数据，目前中心按 flow provider 聚合，不自动执行任意来源能力，没有另建正式业务状态或通用待办调度。

已注册模块的个人实例和调用记录、平台资源、生成回复会校验 access_stamp。本人授权、到期或定义变化后旧快照拒绝使用；其他人的单独授权变化不使本人失效。当前保守绑定整个有效授权集合，可能同时使本人其他 scoped 私人实例失效，尚无按项目的旧草稿自动迁移。重新办理读取模块正式对象；跨人交接不复制私有对话和草稿。未注册 access 的旧模块仍走原有固定角色路径，不代表它们已完成新权限迁移。

Node 与其他远程后端通过 `X-Platform-Access` 短时票据向配置固定地址的 POST `/api/v1/access/remote-decisions` 请求判断，正文为 request_id、operation、permission、facts；票据放同名请求头。先验证原服务 Bearer、从自有数据库读 facts，再请求决策；operation 与本次 invoke/workflow 操作一致。返回 allowed、reason、policy_revision，失效、错误或超时默认拒绝。票据不进入前端、模型、日志、业务持久化，也不是 OAuth 登录或长任务委派。附录 node.mjs 是服务端客户端；默认签名密钥仅在主框架单进程内存，未提供多副本密钥治理。业务提交仍要检查状态、修订、幂等和提交前权限。

跨模块本地交接可通过受控仓储接口，在同一事务内建立独立下游对象，保存唯一来源键及不可变来源版本。拆到不同服务器时需另外落地 outbox/inbox、重复投递去重与最终状态查询；共享组件、授权桥接和中心入口不会自动提供分布式事务或任意 DAG 编排。

实例属于当前登录用户，并记录授权修订。恢复时重新核验身份、组件定义和绑定能力。改变权限后旧实例不继续暴露状态。固定页和对话明确使用同一实例时共享草稿；新建实例相互隔离。

页面的“在对话中继续”将实例关联到本人对话。对话分支复制分支范围内组件的当下已保存状态到新实例，不重放业务动作。它不提供任意历史时刻的草稿回放。正在运行的任务不复制执行，新分支保留输入进入编辑状态；已完成的结果可作为分支参考。

组件定义和版本一旦变化，旧实例暂不可编辑，宿主提示重新创建；当前尚未实现状态迁移。微服务停用或能力无权时组件不可用；离线时保留经过授权的既有状态，阻止新动作。

## 宿主 API 与现有智能能力

新业务优先使用同批 `模块开发快速提示词.md` 和 `templates/module-kit/`。简单工具提供输入输出和一个交互组件；流程业务额外声明正式对象、职责与状态步骤。共享组件保持只使用宿主 SDK，模块服务端使用模板配套的权限接线；并发、幂等和专业规则仍需业务实现。生成包静态检查不能替代安装后的两端真实浏览器验收。

### 身份与入口可见性边界

逐项说明组件入口可发现、可进入、数据可读取、动作可执行的条件。两端使用同一后台授权和字段投影；登录、打开组件或取得模型建议均不增加业务权限。新 system_admin 不自动获得业务材料，模块参与者也不自动获得平台管理或对别人授权的权限。当前中心 identity.manage 可管理实际 grant，受范围限制的委派管理尚未实现。

当前宿主要求登录，没有游客会话、自助注册或通用公开入口策略；不要给现有 manifest/flow/actor 添加自造 public、guest、audience 字段。未来若开放游客组件，应由框架提供统一匿名策略及互相隔离的临时会话，不能共用游客账号。登录后的会话升级应重新授权，不自动提交。公开与内部数据分别投影，历史、附件和办理消息也需检查当前权限；完整参与者消息与持久通知尚未实现。

独立模块 Web 直接地址同样需要后端鉴权；共享组件依赖宿主会话，旧 embedded iframe 不传递平台登录凭据，不能视为 SSO。页面公开下载的代码壳不应内含受保护数据；隐藏菜单、前端只读或模型指令都不是权限边界。公开访问需求作为设计附件交付，在主框架协议正式升级前保留为待接入项。

UI 组件通过 SDK 使用以下接口，不自行重复包装认证。API 前缀 `/api/v1/interactions`，写请求使用已有会话的 CSRF 令牌。

| 方法与路径 | 主要字段/用途 |
| --- | --- |
| GET /catalog | 当前身份可用的组件定义及可用状态 |
| POST /instances | component_id、input、idempotency_key、可选 conversation_id |
| GET /instances | 本人最近 100 个可访问实例 |
| GET /instances/{id} | 当前状态、修订、结果、动作与任务状态 |
| PATCH /instances/{id} | state、expected_revision；冲突返回 409 |
| POST /instances/{id}/actions/{action} | expected_revision、idempotency_key；参数由服务端绑定 |
| POST /instances/{id}/attach | 创建或继续本人关联对话；保留同一实例 |

自然语言仍使用主框架模型配置。模型可选择 core.interaction.open 并提出初始参数，平台校验后创建 UI；业务动作由用户操作组件触发。CopilotKit 1.73.3 的公开 v2/context 与 v2/headless 接口负责对话中注册和渲染：每个宿主实例持有本地呈现注册表，不连接 CopilotKit Runtime。不要替换成缺少真实连接的完整 CopilotKitProvider，后者在生产模式会拒绝初始化。平台未切换到 CopilotKit 的 Agent 后端，也没有新增 AG-UI 执行接口。

## 验收与交付

先验证纯业务函数，再验证 Schema、角色与对象范围，再用真实宿主测试。至少覆盖：固定页面和对话同组件、显式入口、模型工具选择（如适用）、实际服务结果、刷新与重新登录、同组件多实例、分支隔离、并发修订冲突、重复提交、服务离线、任务失败与恢复、定义版本不一致。

“渲染卡片成功”不能替代动作、状态和真实后端验证。无模型入口、替代模型和真实模型测试分别记录。合成数据不声称是真实业务数据；生产级专业效果需领域评测。

对话呈现需要在生产构建后的真实浏览器里测试；开发模式或 jsdom 通过不代表生产初始化正确。验收应覆盖进入已有对话、操作组件、后台结果更新和刷新恢复，并检查页面异常与意外的外部 Runtime 请求。

完成时交付简单操作步骤、架构与数据流、接线边界、测试命令和结果、尚未实现部分。提出统一协议变化时先报告给框架任务，不自行修改认证、通用运行时或其他模块。需要安装自己的组件包、注册自己的能力及补充宿主验收测试时，在明确授权范围内完成并记录。

### Workflow 对象分页与页面组合说明

```markdown
# Workflow 对象分页与页面组合 v1

业务模块是对象状态与权限的唯一权威。平台 Flow 保存个人草稿、导航和对象引用；查询前后核验登录身份、个人 Flow 所有权、授权修订、安装定义、能力与可用性，I/O 后还比较个人 Flow 修订。浏览器不能指定能力、服务地址、可信身份或详情 object_ref。

| 固定 adapter 操作 | input | data | data 大小上限 |
|---|---|---|---|
| objects.list | `{object_type?,cursor?,limit?}` | `{objects,next_cursor}` | 128 KiB |
| objects.read | `{object_ref}` | `{projection}` | 1 MiB |
| objects.detail | `{object_ref,section,cursor?,limit?}` | `{object_ref,revision,items,next_cursor,total}` | 512 KiB |

目录中的 projection 应为摘要；选中对象的 read 投影承载当前有界工作状态；大型行表、问题、历史与其他业务详情按 section 分页。平台不理解 section 的业务意义，具体白名单由业务服务验证。section 格式为 `^[a-z][a-z0-9_.-]{0,119}$`；cursor 是 1 至 2048 字符的不透明字符串。limit 为 1 至 50 的整数，默认 20；返回条数不能超过请求 limit。next_cursor 必须是有效 cursor 或 null，旧本地 adapter 可暂缺省并按 null 处理，远端不能省略。

游标不授予权限。业务服务必须每页重验 actor 与对象范围，并将游标绑定对象类型、对象/section 及相关修订；数据变化应返回 409，客户端从首页重读。detail 返回的 object_ref 必须精确匹配请求，revision 必须为正整数，total 必须为非负整数。列表所有对象类型必须匹配请求 object_type。所有 JSON 仍经过秘密、内联文件字节及总计 2 MiB 限额检查。超出分操作预算是模块协议错误，平台不静默截掉条目或授权动作。

平台同源 POST 路由位于 `/api/v1/flows/instances/{id}`，均检查现有会话和 CSRF：`/objects/list` 接收 `{object_type,cursor?,limit?}`，`/detail` 接收 `{section,cursor?,limit?}`。详情对象只从当前个人 Flow 的 object_ref 取值；list 的 object_type 只能是 provider.object_type 或 provider.related_object_types 中声明的类型。related_object_types 最多 5 个，自身类型隐含允许。

实例 GET 为自身及相关类型各取首页 20 条，保留合并 objects 数组，另返回 `object_pages:[{object_type,next_cursor}]` 供各目录继续分页。最终 Flow 响应独立限制为 2 MiB。已授权对象、动作与详情不能用扩大总响应限额代替分页设计。

定义可选 page_groups，包含 1 至 12 个 `{id,title,steps}` 分组；组 id 唯一，每组有 1 至 8 个不重复且真实存在的 step id。省略时页面沿用单步骤展示。catalog 保留完整命令 schema，实例返回 `step_actions:{stepId:[action摘要]}`，并以 actions 返回当前步骤摘要。摘要包括 id、title、available 及已声明的能力/版本、creates_object、target_step、mode，不重复静态 command_schema。

页面组合只改变呈现；动作仍必须在实例当前 cursor 声明。跨步骤操作先经普通 PATCH 更新个人 cursor 和草稿，再经已有 actions 路由执行，保持角色、对象、状态、CAS、幂等与审计守卫。对话继续只展示当前步骤。中立 Python 模板实现私有对象 list/read 和既有 create/edit 命令，未实现 detail、文件和长任务时明确返回 501。
```

```javascript
import path from 'node:path';
import {fileURLToPath} from 'node:url';
import crypto from 'node:crypto';
import Ajv2020 from 'ajv/dist/2020.js';
import {handle} from './handler.mjs';

const root=path.dirname(fileURLToPath(import.meta.url));
const manifest=JSON.parse(fs.readFileSync(path.join(root,'manifest.json'),'utf8'));
const requestSchema=JSON.parse(fs.readFileSync(path.join(root,'invoke-request.schema.json'),'utf8'));
const validator=new Ajv2020({strict:false,validateFormats:false});
const checkRequest=validator.compile(requestSchema);
const specs=new Map(manifest.capabilities.map(cap=>[cap.id,{cap,input:validator.compile(cap.input_schema),output:validator.compile(cap.output_schema)}]));
const token=process.env.PLATFORM_SERVICE_TOKEN;
if(!token||token.length<24)throw new Error('Set PLATFORM_SERVICE_TOKEN to a private service credential of at least 24 characters.');
const data=path.resolve(process.env.SERVICE_DATA_DIR||path.join(root,'data'));
fs.mkdirSync(data,{recursive:true});
const canonical=value=>Array.isArray(value)?value.map(canonical):value&&typeof value==='object'?Object.fromEntries(Object.keys(value).sort().map(key=>[key,canonical(value[key])])):value;
const hash=value=>crypto.createHash('sha256').update(JSON.stringify(canonical(value))).digest('hex');
let queue=Promise.resolve();
const fail=(code,message,status)=>Object.assign(new Error(message),{code,status});
function authenticated(request){const a=Buffer.from(request.headers.authorization||''),b=Buffer.from('Bearer '+token);return a.length===b.length&&crypto.timingSafeEqual(a,b);}
function reply(response,status,value){response.writeHead(status,{'Content-Type':'application/json; charset=utf-8','Cache-Control':'no-store','X-Content-Type-Options':'nosniff'});response.end(JSON.stringify(value));}
async function execute(request){
  if(!checkRequest(request))throw fail('request_contract','调用协议无效。',422);
  const cache=path.join(data,request.request_id+'.json'),fingerprint=hash(request);
  const saved=fs.existsSync(cache)?JSON.parse(fs.readFileSync(cache,'utf8')):null;
  // Detect altered retries before looking up their replacement capability.
  // Replay only after all current capability, identity and input checks pass.
  if(saved&&saved.fingerprint!==fingerprint)throw fail('idempotency_conflict','相同编号对应不同请求。',409);
  const entry=specs.get(request.capability_id);
  if(!entry||entry.cap.version!==request.capability_version)throw fail('capability_missing','能力或版本不存在。',404);
  const actor=request.context.actor;
  if(!actor.roles.includes(actor.role)||!entry.cap.roles.some(role=>actor.roles.includes(role)))throw fail('forbidden','当前身份无权执行此能力。',403);
  if(!entry.input(request.input))throw fail('input_validation','输入不符合业务契约。',422);
  if(saved)return saved.response;
  const result=await handle(request.input,actor);
  if(!entry.output(result.data)||typeof result.summary!=='string')throw fail('output_contract','业务返回不符合契约。',500);
  const response={protocol_version:'1.1',request_id:request.request_id,capability_id:request.capability_id,capability_version:request.capability_version,summary:result.summary,data:result.data};
  const temporary=cache+'.tmp';fs.writeFileSync(temporary,JSON.stringify({fingerprint,response}),{mode:0o600});fs.renameSync(temporary,cache);
  return response;
}
const server=http.createServer(async(request,response)=>{
  try{
    if(!authenticated(request))return reply(response,401,{error:{code:'service_auth',message:'服务认证失败。'}});
    if(request.method==='GET'&&request.url==='/platform/v1/manifest')return reply(response,200,manifest);
    if(request.method==='GET'&&request.url==='/platform/v1/health')return reply(response,200,{status:'ok'});
    if(request.method!=='POST'||request.url!=='/platform/v1/invoke')return reply(response,404,{error:{code:'not_found',message:'接口不存在。'}});

    for await(const chunk of request){length+=chunk.length;if(length>65536)throw fail('request_size','请求超过模板的 64 KB 限制。',413);chunks.push(chunk);}
    let body;try{body=JSON.parse(Buffer.concat(chunks).toString('utf8'));}catch{throw fail('invalid_json','请求不是有效 JSON。',422);}
    // Serialized requests plus durable receipts prevent simultaneous retries
    // within this one-process reference adapter. Handler side effects still
    // require domain-specific transactional idempotency.
    const work=queue.then(()=>execute(body));queue=work.catch(()=>{});
    reply(response,200,await work);
  }catch(error){reply(response,error.status||500,{error:{code:error.code||'handler_failed',message:error.status?error.message:'处理失败，请检查服务日志与业务实现。'}});}
});
server.listen(Number(process.env.PORT||8032),process.env.HOST||'127.0.0.1',()=>console.log('Component service ready.'));
```

```markdown
# Python 原生权威对象与共享步骤模板

这是中立的“私人记录”示例，不含汇交字段、文件上传、长任务、审核规则或模型调用。Python 模块自己的 `example_workflow_notes` 表是唯一业务状态；平台 Flow 只持有 object_ref、个人草稿和导航。它证明原生 Python 可直接作为流程业务权威，不需要另一套 Node 服务。

受信任模块的 manifest 可选顶层字段 `workflow_adapter: "adapter:create"`。只能引用同一扩展包内简单 Python 文件名与工厂符号，不支持 URL、路径、动态代码或远端 manifest。`Registry.load` 加载 factory；Workflows 初始化时调用 factory(context)。context 为不可变 `LocalWorkflowContext`，仅含 sessions、模块专属 data_dir、module_id，不提供 runtime、模型网关或请求身份。模块仍处于现有受信任本地 Python 扩展边界，不是沙箱。

factory 返回带 `request(*, actor, capability_id, operation, payload, request_id)` 的对象，可同步或异步返回数据对象。可信 actor 由平台每次重新授权后注入；业务模块继续执行对象 ACL、状态与修订守卫。返回对象与远端 workflow v1 data 完全一致，平台同样检查字段、大小、对象匹配和秘密泄露。可选 upload_chunk 方法未实现时返回 501；此模板 request 仅支持 objects.list/read，其余操作明确返回 501。

objects.list 接受可选 object_type、cursor、limit，默认每页 20 条，最多 50 条，返回 `{objects,next_cursor}`；本模板只接受自身对象类型。列表 data 仅含标题摘要，选中后的 objects.read 才返回正文。游标绑定本人、授权修订及记录列表修订快照，列表变化返回 409 后从首页重读。模块仍在每页重新验证权限，游标不授予访问权。单次响应 data 预算为 list 128 KiB、read 1 MiB、detail 512 KiB；整体适配响应和最终 Flow 视图仍最多 2 MiB。超出预算明确报协议错误，不由平台暗中删掉授权动作。大型详情应另实现 objects.detail 按 section 分页，此模板没有详情引擎，明确返回 501。旧本地适配器可暂省 next_cursor，平台按 null 处理；远端适配器必须提供它。

安装时将 backend-python 内容复制到 `extensions/<目录>/` 并加入 extensions/installed.json 的 modules；将 flow 内容复制到 `flows/packs/<目录>/` 并加入 flows/installed.json 的 packs。按需重命名模块、能力、flow ID 和模块表名，保持引用对应。前端使用平台 React 与 `@platform/workflow-sdk`，安装后执行类型检查、生产构建并重启。普通用户不能上传或注册任意 Python 模块。

create/edit/read/list 四个能力也可直接通过既有 invoke 接口使用。create/edit 使用 ctx.session 的同一事务写入模块表和审计；模块不自行 commit，平台 invocation 的幂等回执与业务写入一并提交。edit 使用 owner + expected_revision + draft 状态的 CAS，冲突回滚，不用 UI 草稿直接覆盖。重启后列表和 object_ref 读取同一表；重复原调用返回原回执，不再次建对象。后续新增对象状态机应仍以该表或明确的模块存储为真源，不再镜像远端状态。

共享组件映射为 Picker/Editor：完整页面可按步骤排列，对话只显示当前步骤；两者通过相同 execute/openObject/updateDraft API 工作。组件没有 fetch、登录、服务地址或独立聊天。模板源码提供两个宿主可安装的定义和组件；实际生产浏览器联调需在安装后单独验证，不能仅凭这些文件宣称已完成某业务的浏览器验收。
```

### templates/workflow-module/backend-python/adapter.py

```python
"""Neutral installed Python authority: private notes, no files/jobs or model calls.

Command handlers use the platform invocation transaction and its durable
idempotency receipt. Adapter reads query exactly the same module-owned table.
Do not call commit here or duplicate these objects in a remote service.
"""
import base64
import hashlib
import json

from sqlalchemy import Column, Integer, MetaData, String, Table, Text, insert, select, update

from app.contracts import CapabilityOutput
from app.db import audit, now, uid
from app.errors import require
from app.identity import has_role
from app.job_contract import validate_page_input


OBJECT_TYPE = 'example.note'
metadata = MetaData()
notes = Table('example_workflow_notes', metadata,
    Column('id', String(40), primary_key=True), Column('owner_id', String(40), nullable=False, index=True),
    Column('revision', Integer, nullable=False), Column('state', String(30), nullable=False),
    Column('title', String(200), nullable=False), Column('body', Text, nullable=False),
    Column('created_at', String(50), nullable=False), Column('updated_at', String(50), nullable=False))


def authorized(actor):
    require(has_role(actor, 'member'), 'forbidden', '当前身份不能使用此业务对象。', 403)


def load(db, actor, identifier):
    authorized(actor)
    item = db.execute(select(notes).where(notes.c.id == identifier)).mappings().one_or_none()
    require(item is not None and item['owner_id'] == actor['id'], 'object_scope', '对象不存在或当前身份不可见。', 404)
    return item


def projection(item):
    return {'object_ref': {'object_type': OBJECT_TYPE, 'object_id': item['id']},
        'revision': item['revision'], 'state': item['state'],
        'data': {'title': item['title'], 'body': item['body']},
        'allowed_actions': ['edit'] if item['state'] == 'draft' else [], 'jobs': [], 'updated_at': item['updated_at']}


def listing(db, actor, payload=None):
    authorized(actor)
    payload = payload or {}
    validate_page_input('objects.list', payload)
    require(payload.get('object_type', OBJECT_TYPE) == OBJECT_TYPE, 'object_type', '对象类型不匹配。', 422)
    # Bind the opaque cursor to this private list and its complete revision
    # snapshot. Only small identifiers/revisions are read for the fingerprint;
    # bodies are fetched for the requested page. A cursor grants no authority.
    revisions = list(db.execute(select(notes.c.id, notes.c.revision).where(notes.c.owner_id == actor['id']).order_by(notes.c.id)))
    snapshot = hashlib.sha256(json.dumps([list(row) for row in revisions]).encode()).hexdigest()
    binding = {'owner': actor['id'], 'authorization_revision': actor.get('authorization_revision', 1),
               'object_type': OBJECT_TYPE, 'snapshot': snapshot}
    offset, limit = 0, payload.get('limit', 20)
    if payload.get('cursor'):
        try:
            raw = payload['cursor']
            cursor = json.loads(base64.urlsafe_b64decode(raw + '=' * (-len(raw) % 4)))
        except (ValueError, UnicodeError):
            cursor = None
        require(isinstance(cursor, dict) and set(cursor) == {*binding, 'offset'}
                and type(cursor['offset']) is int and cursor['offset'] >= 0,
                'cursor_invalid', '分页游标无效。', 422)
        require(all(cursor[key] == value for key, value in binding.items()), 'revision_conflict', '记录列表已变化，请重新读取。', 409)
        require(cursor['offset'] <= len(revisions), 'cursor_invalid', '分页游标无效。', 422)
        offset = cursor['offset']
    values = list(db.execute(select(notes).where(notes.c.owner_id == actor['id']).order_by(notes.c.updated_at.desc(), notes.c.id).offset(offset).limit(limit)).mappings())
    latest = list(db.execute(select(notes.c.id, notes.c.revision).where(notes.c.owner_id == actor['id']).order_by(notes.c.id)))
    require(latest == revisions, 'revision_conflict', '读取期间记录列表已经变化，请重试。', 409)
    next_cursor = None
    if offset + len(values) < len(revisions):
        next_cursor = base64.urlsafe_b64encode(json.dumps({**binding, 'offset': offset + len(values)}, separators=(',', ':')).encode()).decode().rstrip('=')
    # A directory page does not repeat every object's body. Read the selected
    # record for its full projection; this keeps even 50 entries below 128 KiB.
    return {'objects': [{**projection(item), 'data': {'title': item['title']}} for item in values], 'next_cursor': next_cursor}


def create_note(ctx, payload):
    authorized(ctx.actor)
    identifier, stamp = uid(), now()
    command = payload['command']
    ctx.session.execute(insert(notes).values(id=identifier, owner_id=ctx.actor['id'], revision=1, state='draft',
        title=command['title'], body=command['body'], created_at=stamp, updated_at=stamp))
    audit(ctx.session, ctx.actor['id'], 'example.note.create', identifier, revision=1)
    return CapabilityOutput('已创建记录。', {'projection': projection(load(ctx.session, ctx.actor, identifier))})


def edit_note(ctx, payload):
    item = load(ctx.session, ctx.actor, payload['object_id'])
    require(item['state'] == 'draft', 'state_conflict', '当前对象不允许编辑。', 409)
    require(item['revision'] == payload['expected_revision'], 'revision_conflict', '对象版本已经变化，请重新读取。', 409)
    command, revision = payload['command'], item['revision'] + 1
    changed = ctx.session.execute(update(notes).where(notes.c.id == item['id'], notes.c.owner_id == ctx.actor['id'],
        notes.c.revision == payload['expected_revision'], notes.c.state == 'draft').values(
        title=command['title'], body=command['body'], revision=revision, updated_at=now()))
    require(changed.rowcount == 1, 'revision_conflict', '另一个请求已经修改该对象。', 409)
    audit(ctx.session, ctx.actor['id'], 'example.note.edit', item['id'], revision=revision)
    return CapabilityOutput('已保存记录。', {'projection': projection(load(ctx.session, ctx.actor, item['id']))})


def read_note(ctx, payload):
    return CapabilityOutput('已读取当前记录。', {'projection': projection(load(ctx.session, ctx.actor, payload['object_id']))})


def list_notes(ctx, payload):
    return CapabilityOutput('已读取本人记录。', listing(ctx.session, ctx.actor))


class Adapter:
    def __init__(self, context):
        self.sessions = context.sessions
        # Schema creation is installation/startup work, not a second object store.
        with self.sessions() as db:
            metadata.create_all(db.get_bind())

    def request(self, *, actor, capability_id, operation, payload, request_id):
        require(operation in {'objects.list', 'objects.read'}, 'workflow_adapter_missing', '此模块未实现文件或长任务适配。', 501)
        with self.sessions() as db:
            if operation == 'objects.list':
                return listing(db, actor, payload)
            ref = payload['object_ref']
            require(ref['object_type'] == OBJECT_TYPE, 'object_type', '对象类型不匹配。', 422)
            return {'projection': projection(load(db, actor, ref['object_id']))}
```

```tsx
import definition from './flow.json';

/** Both hosts mount these exact components. The SDK owns requests and identity. */
function NoteForm(props:WorkflowStepProps & {event:'create'|'edit'}) {
  const source=props.event==='edit' ? props.projection?.data : null;
  const title=String(props.draft.title ?? source?.title ?? '');
  const body=String(props.draft.body ?? source?.body ?? '');
  const allowed=props.actions.find(action=>action.id===props.event)?.available;
  return <section>
    <label>标题<input aria-label="标题" value={title} disabled={props.busy}
      onChange={event=>props.updateDraft({...props.draft,title:event.target.value})}/></label>
    <label>内容<textarea aria-label="内容" value={body} disabled={props.busy}
      onChange={event=>props.updateDraft({...props.draft,body:event.target.value})}/></label>
    <button type="button" disabled={props.busy||!allowed||!title.trim()}
      onClick={()=>void props.execute(props.event,{title,body})}>{props.event==='create'?'创建记录':'保存记录'}</button>
  </section>;
}

function Picker(props:WorkflowStepProps) {
  const objectType=definition.flows[0].provider.object_type;
  const records=props.objects.filter(item=>item.object_ref.object_type===objectType);
  const hasMore=props.objectPages.some(page=>page.object_type===objectType&&page.next_cursor);
  const [loading,setLoading]=useState(false),[error,setError]=useState('');
  const requested=useRef(false);
  async function loadMore(){
    if(props.busy||requested.current||!hasMore)return;
    requested.current=true;setLoading(true);setError('');
    try{await props.loadMoreObjects(objectType);}
    catch(error){setError(error instanceof Error?error.message:'记录加载失败，请重试。');}
    finally{requested.current=false;setLoading(false);}
  }
  return <section><h3>本人记录</h3>
    {records.map(item=><button type="button" key={item.object_ref.object_id} disabled={props.busy}
      onClick={()=>void props.openObject(item.object_ref.object_id)}>{String(item.data.title)}</button>)}
    <p>已加载 {records.length} 条记录</p>
    {hasMore&&<button type="button" disabled={props.busy||loading} onClick={()=>void loadMore()}>
      {loading?'正在加载记录…':'加载更多记录'}</button>}
    {loading&&<p role="status">正在读取下一页记录…</p>}
    {error&&<p role="alert">{error}</p>}
    {props.projection&&<button type="button" disabled={props.busy} onClick={()=>props.navigate('edit')}>编辑所选记录</button>}
    <h3>创建记录</h3><NoteForm {...props} event="create"/>
  </section>;
}

function Editor(props:WorkflowStepProps) {
  return props.projection ? <section>
    <p>当前对象修订：{props.projection.revision}</p><NoteForm {...props} event="edit"/>
```

### Access v1 执行与兼容边界

```markdown
# 可注册范围授权 v1

`definition.schema.json` 是独立权限包；不可向已有 manifest 或远程 actor 随意添加字段。`binding.schema.json` 是主框架受控管理入口创建的实际用户授权。模块安装仅注册定义，不携带真实人员授权。

每个权限、角色模板、办理视图与待办源 ID 以 `module_id + '.'` 开头；能力映射仅绑定本模块。模块命名空间不得相互包含。scope 的所有键值同时匹配可信仓库 facts，每一条授权独立判断，不能跨授权拼接范围。facts 值可为非空字符串，或表达已验证关系的非空字符串数组；浏览器 payload 和模型输出不是可信事实。

角色 `required_scope` 至少有一个范围维度，不接受 `*` 通配授权。已授予角色保留权限快照，并与当前模板权限取交集；升级新增权限需另行授权，收紧立即生效。职责分离 guards 对最终权限统一生效，双角色不能绕过。禁用、撤权、过期、缺失事实和未知动作默认拒绝。业务状态机仍由模块实现，授权允许不等于状态转换成功。

`experiences.required_permissions` 要求全部满足，`step_ids` 为可选的可见步骤集合。无对象的目录只检查有效授权存在；执行仍需 fresh facts。`workitem_sources` 是聚合元数据，不自动运行代码。列表查询必须先落实授权范围再分页、计数和统计。

Python 模块使用 `ctx.access.check(ctx.actor, permission, trusted_facts)`；Node 或远端 Python 通过受认证的适配接口取得等价决定，不能由浏览器直接提交授权 facts。当前角色目录与 invoke actor 无需私加新角色字段，动态角色由独立注册表保存。

`AccessControl(sessions)` 的管理接口仅供已验证 `identity.manage` 的主框架管理入口调用；核心不接受客户端自称管理员。决策方法只读，不另开写审计事务。`AccessControl.from_session(session)` 借用业务事务，禁止管理写入，也不会提交调用者事务。

真实引擎为 Casbin 1.43.0，使用框架内固定的 RBAC domain 模型：每条完整授权作为一个 domain，由框架校验 scope 与 guard 后交给 Casbin。模块不能注入匹配表达式。SQLite 保存定义、角色绑定、到期与撤销、修订及管理审计；引擎可经同一门面替换。Casbin 不替代登录、列表范围过滤、正式状态机、幂等或事务检查。

`authorization_stamp(actor)` 绑定当前策略定义修订及此人的有效授权。其他人的角色分配不会打断当前人的流程；本人撤权、到期、定义变化、禁用再启用均使旧实例授权快照失效。长任务和分布式提交仍需要明确的提交点与再次校验，不能把一次允许决定当永久通行证。

接口主要方法：`register_definition`、`grant`、`revoke`、`set_enabled`、`definitions`、`bindings`、`check`、`check_command`、`has_permission`、`matching_scopes`、`capability_permission(s)`、`experiences`、`module_registered`、`authorization_stamp`。`has_permission` 只供目录；`matching_scopes` 是 OR-of-AND 的完整范围组，查询适配层不能扁平合并。

`command_mappings.command` 用于字符串子命令选择器。workflow v1 的 `input.command` 是结构化事务信封，应为每个具体能力配置无 command 的权限映射；结构化信封不会被当作子命令名称。未知字符串子命令拒绝，不能回退到普通能力权限；同一个能力不能混合无条件映射和字符串子命令映射。

开源资料：[Casbin 域内 RBAC](https://casbin.apache.org/docs/rbac-with-domains/)、[PyCasbin](https://github.com/apache/casbin-pycasbin)。
```

````markdown
# Node.js 与其他语言的统一权限判断

主框架对已注册 access definition 的远程调用额外发送 `X-Platform-Access` 短时票据。原 manifest / invoke / actor JSON 不变；旧 actor.roles 不用于表达新模块角色。票据含最终用户授权快照、模块能力与连接修订、请求号和操作，由主框架 HMAC 签名，最长 60 秒；默认进程密钥使重启前票据失效。

1. 模块先验证已有连接 Bearer，按原协议读取 request_id 和 actor；拒绝未经认证的调用。
2. 从模块自己的数据库读取对象事实，例如 project_id、owner_id；不能把浏览器提交的 owner_id 当事实。
3. 用部署时配置的主框架 callback URL 创建 `createAccessClient`，调用其返回函数：

```js
const decide = createAccessClient({
  callbackUrl: process.env.PLATFORM_ACCESS_DECISION_URL,
});
const decision = await decide({
  ticket: request.headers['x-platform-access'],
  requestId: body.request_id,
  operation: 'invoke', // workflow 适配使用对应 objects.read 等真实 operation
  permission: 'example-module.item.read',
  facts: { project_id: row.project_id, owner_id: row.owner_id },
});
if (!decision.allowed) throw new Error('当前无权办理');
```

4. 允许后，模块仍在事务内检查业务状态、预期修订、幂等和职责分离。提交前重新判断，避免把一次允许当永久授权。

票据不传入网页、模型、日志或持久化业务数据；callback URL 仅来自服务端配置，不能采用表单或微服务请求指定的地址。示例禁止重定向，限制请求、响应体积和超时，非 2xx / 无效响应 / 连接失败均拒绝，不能降级为旧角色允许。

票据仅允许其能力已登记的权限，不可切换用户、模块、连接、请求或操作。facts 的可信性来自已受控接入的业务服务，桥接不能防止一个已被攻陷或恶意的权威模块谎报自身对象事实；这与模块直接运行授权代码处于相同信任边界。服务对自己的 facts 负责，主框架对身份、授权和票据有效性负责。

当前默认随机密钥适合单主框架进程。多 worker / 多副本部署须统一配置安全签名密钥或集中决策入口，并处理密钥轮转；否则分发到另一进程的票据会拒绝。此票据是单次调用内的短时决策通道，不是 OAuth 登录、第三方通用访问令牌或长任务委托协议。
````

### templates/remote-access-client/node.mjs

```javascript
/** Trusted server-side client. Never import this into a browser bundle. */
export function createAccessClient({ callbackUrl, timeoutMs = 4000, fetchImpl = globalThis.fetch }) {
  const endpoint = new URL(callbackUrl);
  if (!['http:', 'https:'].includes(endpoint.protocol) || endpoint.username || endpoint.password ||
      endpoint.hash || endpoint.search || endpoint.pathname !== '/api/v1/access/remote-decisions') {
    throw new Error('Invalid configured access-decision endpoint');
  }
  if (!Number.isInteger(timeoutMs) || timeoutMs < 1 || timeoutMs > 10000) {
    throw new Error('Access decision timeout must be 1-10000 milliseconds');
  }
  // callbackUrl comes exclusively from deployment configuration. No URL, actor,
  // role, token destination or fetch options are accepted from invocation input.
  return async function decideAccess({ ticket, requestId, operation, permission, facts }) {
    const deny = reason => ({ allowed: false, reason, policy_revision: 0 });
    if (typeof ticket !== 'string' || ticket.length === 0 || ticket.length > 12288) return deny('access_ticket_invalid');
    let body;
    try { body = JSON.stringify({ request_id: requestId, operation, permission, facts }); }
    catch { return deny('access_decision_contract'); }
    if (Buffer.byteLength(body, 'utf8') > 16384) return deny('access_decision_size');
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), timeoutMs);
    try {
      const response = await fetchImpl(endpoint, {
        method: 'POST', redirect: 'error', signal: controller.signal,
        headers: { 'Content-Type': 'application/json', 'X-Platform-Access': ticket }, body,
      });
      if (!response.ok) return deny('access_decision_unavailable');
      // Read bounded bytes rather than response.json() on an unbounded body.
      const reader = response.body.getReader();
      const chunks = []; let size = 0;
      while (true) {
        const { value, done } = await reader.read();
        if (done) break;
        size += value.byteLength;
        if (size > 4096) { await reader.cancel(); return deny('access_decision_response_size'); }
        chunks.push(Buffer.from(value));
      }
      const result = JSON.parse(Buffer.concat(chunks).toString('utf8'));
      if (typeof result.allowed !== 'boolean' || typeof result.reason !== 'string' ||
          !Number.isInteger(result.policy_revision) || result.policy_revision < 0 ||
          (result.allowed && (result.reason !== 'allowed' || result.policy_revision < 1))) return deny('access_decision_invalid');
      return { allowed: result.allowed, reason: result.reason, policy_revision: result.policy_revision };
    } catch {
      return deny('access_decision_unavailable');
    } finally {
      clearTimeout(timer);
    }
  };
}
```

```python
"""Replace this pure business function; it has no platform or web dependency."""

MAX_TEXT_LENGTH = 20_000


def analyze(payload: dict) -> dict:
    if not isinstance(payload, dict) or set(payload) != {"text"}:
        raise ValueError("expected exactly the text field")
    text = payload["text"]
    if not isinstance(text, str) or not 1 <= len(text) <= MAX_TEXT_LENGTH or not text.strip():
        raise ValueError("text outside supported bounds")
    # Preserve line boundaries, remove surrounding whitespace and collapse
    # whitespace within a line. Counts are Unicode code points, not graphemes.
    text = text.replace("\r\n", "\n").replace("\r", "\n")
    normalized = "\n".join(" ".join(line.split()) for line in text.split("\n")).strip()
    data = {
        "normalized_text": normalized,
        "character_count": len(normalized),
        "line_count": len(normalized.split("\n")),
        "segment_count": len(normalized.split()),
    }
    return {
        "summary": f"已整理文本：{data['character_count']} 个字符，{data['line_count']} 行。",
        "data": data,
    }
```

```python
Run from any working directory: python <generated-package>/tests/self_test.py

from runpy import run_path

import json
import unittest

SDK = run_path(str(ROOT / "backend" / "_module_kit.py"))

    def __init__(self, allowed=True, organization_id="org-a"):
        self.allowed, self.organization_id, self.calls = allowed, organization_id, []

    def check(self, actor, permission, facts):
        self.calls.append((actor.copy(), permission, facts.copy()))
        return {"allowed": self.allowed if facts == {"organization_id": self.organization_id} else False}
```

````markdown
## 职责和范围

| 职责 | 允许动作 | 范围与条件 | 页面和对话 |
| --- | --- | --- | --- |
| 提交者 `__MODULE_ID__.author` | 读取、创建、编辑、提交 | 每份 grant 同时包含 project_id 和 organization_id；只能编辑、提交本人草稿 | 选择、填写、审核结果 |
| 审核人 `__MODULE_ID__.reviewer` | 读取、审核 | 同样的完整项目/机构范围；只审核别人提交的记录 | 选择、只读内容、审核 |

本参考明确允许同一授权项目和机构内协作读取记录内容。目录先逐对象中央授权，再分页；不会返回范围外记录数量。提交者拥有其他项目的审核职责时，仍按本次对象事实核验，不能把不同授权的范围拼接。`allowed_actions` 只是状态与作者关系形成的候选，宿主再过滤能力权限；实际执行始终重新中央授权、检查正式状态和 expected_revision。

`frontend/flow.json` 中的 `state_machine` 声明草稿、待审核、已通过及动作之间的对应关系。`backend/business.mjs` 读取这同一声明执行正式状态转移，固定页面和对话也读取同一状态名称；提交后不再允许编辑。框架调试器绘制的是正式状态，用户切换 `pick/edit/review` 导航步骤不会改变业务状态。状态机声明不执行任意表达式，`guard_description` 仅说明条件，实际权限、作者关系、修订和意见校验仍由业务后端执行。增加新动作时同时修改能力、共享步骤、状态机及后端规则并测试，不能只在图上画一条线。

项目与机构关系从受控 `MODULE_PROJECTS_FILE` 加载；浏览器只选择 project_id，不能指定可信 organization_id。已有系统应把此查询改为原项目仓储。修改项目配置后旧对象机构不一致会拒绝读取，不能靠重命名配置把旧数据移交其他机构。

## 独立验证与启动

要求 Node.js 24；无需 npm install。先确认使用正确版本：

```powershell
node --version
node --test tests/workflow.test.mjs
```

测试使用临时数据库、随机端口和合成中央决策 HTTP 服务，结束会清理自己的临时目录。它实际验证 HTTP、SQLite、幂等、重启、并发、权限失败和分页，但不代表已经在真实平台注册或通过生产浏览器验证。

部署时在受保护位置准备项目 JSON，可参考 `backend/projects.example.json` 的结构；合成项目编号不能冒充真实项目。由管理员设置服务进程环境：

```powershell
$env:SERVICE_DATA_DIR = 'D:\private-module-data\__PACK_NAME__'
$env:MODULE_PROJECTS_FILE = 'D:\private-module-config\__PACK_NAME__-projects.json'
$env:PLATFORM_ACCESS_DECISION_URL = 'http://127.0.0.1:8030/api/v1/access/remote-decisions'
# PLATFORM_SERVICE_TOKEN 通过私有部署配置注入，至少 24 字符；不要写进源码或共享脚本。
$env:PORT = '8040'
node backend/server.mjs
```

示例地址和路径须改为实际部署环境。服务只监听回环地址；跨机器部署通过受控网关、TLS 与网络访问策略另行配置。启动只输出就绪端口，不输出凭据。停止使用 Ctrl+C；数据保存在 `records.sqlite`，再次使用同一目录启动会恢复对象和回执。参考包最多 1000 条记录、100 个已配置项目；大规模服务应实现仓储范围查询，不直接增加扫描量。

所有 `/platform/v1/health`、`manifest`、`invoke` 和 `workflow/*` 接口要求私有服务 Bearer。业务还要求平台本次调用的短时 `X-Platform-Access` 票据；单有服务 Bearer 或伪造 actor 不构成业务授权。中央连接失败、过期票据和撤权都拒绝，禁止退回固定角色放行。

## 安装到平台

1. 服务进程启动后，由平台管理员录入受控地址与私有凭据，发现 manifest，保持禁用。
2. 把 `frontend/` 的文件复制到平台 `flows/packs/__PACK_NAME__/`，在 `flows/installed.json` 的 `packs` 追加 `__PACK_NAME__`，保留其他条目。使用宿主 React 和 `@platform/workflow-sdk`，不在此目录另装 React。
3. 按平台规程复核提示词、重建快照、执行一致性检查，类型检查和生产构建，再重启受控平台载入 flow。仅复制文件不会热加载流程；权限附件注册前应确认该流程已被宿主载入。不要用开发服务器成功替代生产验收。
4. 管理员审核并注册 `backend/access-definition.json`。安装定义不自动授予任何用户业务权限。
5. 核验 flow 和能力绑定后执行平台七项接入检查，包含服务身份、接口、模块主动确认及已安装宿主。全部通过后在验收有效期内发布；失败时按报告修复并重新验收。具有 `identity.manage` 的管理者给合成测试用户分别授予提交者、审核人，scope 中同时填入项目和机构的准确值，无通配符。
6. 从“我的业务”或 `/flow __MODULE_ID__.workflow` 分别在页面与对话办理。验证 A 创建、保存和提交，B 用自己的流程审核，A 刷新看到结果；再验证撤权、重新登录、同一实例继续、分支不重放正式写入。

服务被禁用或中央授权变化时由现有平台拒绝旧实例；服务不自建个人会话。恢复同一个私人草稿须使用原 instance_id，跨人交接只共享正式对象，不复制私有对话。

## 边界与渐进适配

已实现：有限项目记录、原子 SQLite 状态/修订/幂等回执、中央范围决策、对象读写、授权后目录分页、共享前端组件。SDK 的事务与回执不覆盖外部写操作；跨服务器事务需要另行设计。

未实现：文件、长任务、明细分页、模型调用、通知、游客、SSO、长期委派和通用跨角色事件调度。未实现的 workflow 方法返回 501。流程导航、聊天分支与“我的业务”由现有主框架提供，不能在此包中伪造其状态。

已有独立服务可先保留原 API 和数据库：将既有对象映射为 projection，将动作包装为 invoke，将项目/机构/作者事实从原仓储读取，再接中央授权。保留原事务，把请求编号和正式写入原子保存。只把业务组件迁入 `frontend/`，不重写登录、聊天、原计算逻辑或全部页面。

交付前记录真实平台版本、提示词指纹和验收证据；独立测试通过与真实宿主联调通过应分开记录。
````

### templates/module-kit/blueprints/workflow-node/backend/business.mjs

```javascript
/** Business changes belong here. SDK owns transport/transactions; the platform owns identity and grants. */
import { randomUUID } from "node:crypto";
import { readFileSync } from "node:fs";
import { Store } from "../sdk/node/store.mjs";
import { compile, requireThat, fail } from "../sdk/node/runtime.mjs";

export const MODULE_ID = "__MODULE_ID__";
export const OBJECT_TYPE = `${MODULE_ID}.record`;
// The same installed declaration drives visualization and authoritative state
// changes. It is static trusted module code, never a URL or a user expression.
export const stateMachine = JSON.parse(
  readFileSync(new URL("../frontend/flow.json", import.meta.url), "utf8"),
).flows[0].state_machine;
function transitionTarget(state, action) {
  const choices = stateMachine.transitions.filter(
    (item) => item.from === state && item.action_id === action,
  );
  requireThat(
    choices.length === 1,
    "state_conflict",
    "当前状态不允许此操作。",
    409,
  );
  return choices[0].to;
}
const identity = {
  type: "string",
  pattern: "^[A-Za-z0-9][A-Za-z0-9._:-]{0,99}$",
};
const projectCheck = compile({
  type: "array",
  minItems: 1,
  maxItems: 100,
  items: {
    type: "object",
    required: ["project_id", "organization_id", "title"],
    properties: {
      project_id: identity,
      organization_id: identity,
      title: { type: "string", minLength: 1, maxLength: 160 },
    },
    additionalProperties: false,
  },
});
const listCheck = compile({
  type: "object",
  additionalProperties: false,
  properties: {
    object_type: { type: "string", const: OBJECT_TYPE },
    cursor: { type: "string", minLength: 1, maxLength: 2048 },
    limit: { type: "integer", minimum: 1, maximum: 50 },
  },
});
const readCheck = compile({
  type: "object",
  additionalProperties: false,
  required: ["object_ref"],
  properties: {
    object_ref: {
      type: "object",
      additionalProperties: false,
      required: ["object_type", "object_id"],
      properties: {
        object_type: { type: "string", const: OBJECT_TYPE },
        object_id: {
          type: "string",
          pattern: "^[A-Za-z0-9][A-Za-z0-9_-]{0,99}$",
        },
      },
    },
  },
});
const ordinaryDenials = new Set([
  "grant_scope_mismatch",
  "actor_relation_mismatch",
  "separation_of_duties",
  "fact_condition_failed",
]);
export function createBusiness({ filename, projects, decide }) {
  requireThat(
    projectCheck(projects) &&
      new Set(projects.map((item) => item.project_id)).size === projects.length,
    "project_config",
    "项目仓库配置无效或包含重复编号。",
    500,
  );
  // This trusted deployment configuration is the project repository for the reference package.
  // An existing service replaces this lookup with its own repository, never input.organization_id.
  const repository = new Map(
    projects.map((item) => [item.project_id, Object.freeze({ ...item })]),
  );
  const store = new Store(filename);
  store.db.exec(`CREATE TABLE IF NOT EXISTS records(
    id TEXT PRIMARY KEY, project_id TEXT NOT NULL, organization_id TEXT NOT NULL, author_id TEXT NOT NULL,
    title TEXT NOT NULL, body TEXT NOT NULL, state TEXT NOT NULL, revision INTEGER NOT NULL,
    reviewer_id TEXT, review_note TEXT, updated_at TEXT NOT NULL);`);
  function facts(record) {
    return {
      project_id: record.project_id,
      organization_id: record.organization_id,
      author_id: record.author_id,
    };
  }
  function load(id) {
    const record = store.db.prepare("SELECT * FROM records WHERE id=?").get(id);
    requireThat(
      record &&
        repository.get(record.project_id)?.organization_id ===
          record.organization_id,
      "object_scope",
      "记录不存在或项目配置已变化。",
      404,
    );
    return record;
  }
  async function decision(
    body,
    ticket,
    operation,
    permission,
    trustedFacts,
    optional = false,
  ) {
    const result = await decide({
      ticket,
      requestId: body.request_id,
      operation,
      permission: `${MODULE_ID}.${permission}`,
      facts: trustedFacts,
    });
    requireThat(
      result &&
        typeof result.allowed === "boolean" &&
        Number.isSafeInteger(result.policy_revision),
      "access_denied",
      "中央授权不可用。",
      403,
    );
    if (result.allowed) return result;
    if (
      optional &&
      ordinaryDenials.has(result.reason) &&
      result.policy_revision > 0
    )
      return result;
    throw fail("access_denied", "当前授权不允许此操作，请重新核验授权。", 403);
  }
  function projection(record, actor, summary = false) {
    const own = record.author_id === actor.id;
    const actions = stateMachine.transitions
      .filter(
        (item) =>
          item.from === record.state &&
          (item.action_id === "approve" ? !own : own),
      )
      .map((item) => item.action_id);
    return {
      object_ref: { object_type: OBJECT_TYPE, object_id: record.id },
      revision: record.revision,
      state: record.state,
      data: summary
        ? {
            title: record.title,
            project_id: record.project_id,
            organization_id: record.organization_id,
          }
        : {
            title: record.title,
            body: record.body,
            project_id: record.project_id,
            organization_id: record.organization_id,
            author_id: record.author_id,
            reviewer_id: record.reviewer_id,
            review_note: record.review_note,
          },
      allowed_actions: actions,
      jobs: [],
      updated_at: record.updated_at,
    };
  }
  async function list(body, ticket, operation, payload) {
    requireThat(listCheck(payload), "input_contract", "目录参数无效。");
    let policyRevision;
    const accepted = [];
    // Even an empty database checks a live ticket against configured trusted project facts.
    for (const project of repository.values()) {
      const result = await decision(
        body,
        ticket,
        operation,
        "read",
        {
          project_id: project.project_id,
          organization_id: project.organization_id,
        },
        true,
      );
      requireThat(
        policyRevision === undefined ||
          policyRevision === result.policy_revision,
        "access_denied",
        "读取期间权限定义已变化。",
        403,
      );
      policyRevision = result.policy_revision;
    }
    // Small-reference policy: at most 1000 records. Replace this with repository scope queries at scale.
    // Crucially, authorization happens before pagination and no unauthorized totals are returned.
    for (const record of store.db
      .prepare("SELECT * FROM records ORDER BY id")
      .all()) {
      if (
        repository.get(record.project_id)?.organization_id !==
        record.organization_id
      )
        continue;
      const result = await decision(
        body,
        ticket,
        operation,
        "read",
        facts(record),
        true,
      );
      requireThat(
        policyRevision === result.policy_revision,
        "access_denied",
        "读取期间权限定义已变化。",
        403,
      );
      if (result.allowed) accepted.push(record);
    }
    const binding = {
      module: MODULE_ID,
      actor: body.context.actor,
      policyRevision,
      snapshot: store.fingerprint(
        accepted.map((record) => [record.id, record.revision]),
      ),
    };
    const offset = store.offset(payload.cursor, binding),
      limit = payload.limit || 20;
    requireThat(
      offset <= accepted.length,
      "cursor_invalid",
      "分页游标超出目录范围。",
    );
    return {
      objects: accepted
        .slice(offset, offset + limit)
        .map((record) => projection(record, body.context.actor, true)),
      next_cursor:
        offset + limit < accepted.length
          ? store.cursor(binding, offset + limit)
          : null,
    };
  }
  async function invoke({ body, ticket }) {
    return store.transaction(async () => {
      const action = body.capability_id.slice(MODULE_ID.length + 1);
      requireThat(
        body.capability_id === `${MODULE_ID}.${action}` &&
          ["create", "edit", "submit", "approve", "read", "list"].includes(
            action,
          ),
        "capability_unknown",
        "未声明的能力。",
      );
      if (action === "list")
        return {
          summary: "已读取授权范围内的项目记录。",
          data: await list(body, ticket, "invoke", body.input),
        };
      if (action === "read") {
        const record = load(body.input.object_id);
        await decision(body, ticket, "invoke", "read", facts(record));
        return {
          summary: "已读取当前记录。",
          data: { projection: projection(record, body.context.actor) },
        };
      }
      const cached = store.receipt(body);
      const record = cached
        ? load(cached.objectId)
        : action === "create"
          ? null
          : load(body.input.object_id);
      const project =
        action === "create"
          ? repository.get(body.input.command.project_id)
          : null;
      requireThat(
        action !== "create" || project,
        "project_unknown",
        "所选项目不在服务端项目仓库。",
      );
      const trustedFacts = record
        ? facts(record)
        : { ...project, author_id: body.context.actor.id };
      delete trustedFacts.title;
      await decision(body, ticket, "invoke", action, trustedFacts);
      if (cached) return cached.response; // Reauthorize every retry, including after restart; never replay a write.
      const stamp = new Date().toISOString();
      let id = record?.id;
      if (action === "create") {
        requireThat(
          store.db.prepare("SELECT count(*) AS n FROM records").get().n < 1000,
          "capacity_limit",
          "参考包最多保存 1000 条记录，请扩展仓储后继续。",
          413,
        );
        requireThat(
          body.input.command.title.trim().length > 0,
          "title_required",
          "请输入标题。",
        );
        id = randomUUID();
        store.db
          .prepare("INSERT INTO records VALUES (?,?,?,?,?,?,?,?,?,?,?)")
          .run(
            id,
            project.project_id,
            project.organization_id,
            body.context.actor.id,
            body.input.command.title,
            body.input.command.body,
            stateMachine.initial,
            1,
            null,
            null,
            stamp,
          );
      } else {
        requireThat(
          record.revision === body.input.expected_revision,
          "revision_conflict",
          "记录已更新，请重新读取。",
          409,
        );
        const own = record.author_id === body.context.actor.id;
        requireThat(
          action === "approve" ? !own : own,
          "separation_of_duties",
          "当前办理人与记录作者的关系不符合要求。",
          403,
        );
        const nextState = transitionTarget(record.state, action);
        if (action === "edit")
          requireThat(
            body.input.command.title.trim().length > 0,
            "title_required",
            "请输入标题。",
          );
        if (action === "approve")
          requireThat(
            body.input.command.note.trim().length > 0,
            "note_required",
            "请输入审核意见。",
          );
        const changed = store.db
          .prepare(
            "UPDATE records SET title=?,body=?,state=?,revision=revision+1,reviewer_id=?,review_note=?,updated_at=? WHERE id=? AND revision=? AND state=?",
          )
          .run(
            action === "edit" ? body.input.command.title : record.title,
            action === "edit" ? body.input.command.body : record.body,
            nextState,
            action === "approve" ? body.context.actor.id : null,
            action === "approve" ? body.input.command.note : null,
            stamp,
            id,
            body.input.expected_revision,
            record.state,
          );
        requireThat(
          changed.changes === 1,
          "revision_conflict",
          "另一请求已修改记录。",
          409,
        );
      }
      // A final fresh central check precedes the atomic commit. Denial rolls back both object and receipt.
      await decision(body, ticket, "invoke", action, trustedFacts);
      const response = {
        summary: {
          create: "已创建草稿。",
          edit: "已保存记录。",
          submit: "已提交，等待其他审核人办理。",
          approve: "已审核通过。",
        }[action],
        data: { projection: projection(load(id), body.context.actor) },
      };
      store.saveReceipt(body, id, response);
      return response;
    });
  }
  async function workflow({ body, operation, ticket }) {
    return store.transaction(async () => {
      if (operation === "objects.list")
        return list(body, ticket, operation, body.input);
      requireThat(
        operation === "objects.read",
        "workflow_unsupported",
        "此参考包未实现明细分页、文件或长任务适配。",
        501,
      );
      requireThat(
        readCheck(body.input),
        "input_contract",
        "对象引用不符合契约。",
      );
      const record = load(body.input.object_ref.object_id);
      await decision(body, ticket, operation, "read", facts(record));
      return { projection: projection(record, body.context.actor) };
    });
  }
  // The transport dispatches through these exact maps and validates complete
  // manifest coverage before registration; the handshake never calls them.
  const handlers = Object.fromEntries(
    ["create", "edit", "submit", "approve", "read", "list"].map((action) => [
      `${MODULE_ID}.${action}`,
      invoke,
    ]),
  );
  const workflowHandlers = {
    "objects.list": workflow,
    "objects.read": workflow,
  };
  return {
    invoke,
    workflow,
    handlers,
    workflowHandlers,
    close: () => store.close(),
  };
}
```

```javascript
import { readFileSync, mkdirSync } from "node:fs";
import path from "node:path";
import { fileURLToPath, pathToFileURL } from "node:url";
import { createModuleServer, requireThat } from "../sdk/node/runtime.mjs";
import { createAccessClient } from "../sdk/node/access-client.mjs";
import { createBusiness } from "./business.mjs";

const root = path.dirname(fileURLToPath(import.meta.url));
export const manifest = JSON.parse(
  readFileSync(path.join(root, "manifest.json"), "utf8"),
);
export const registration = JSON.parse(
  readFileSync(path.join(root, "registration.json"), "utf8"),
);
export function createService({
  token,
  callbackUrl,
  filename,
  projects,
  fetchImpl,
}) {
  const business = createBusiness({
    filename,
    projects,
    decide: createAccessClient({ callbackUrl, fetchImpl }),
  });
  try {
    const server = createModuleServer({
      manifest,
      registration,
      token,
      handlers: business.handlers,
      workflowHandlers: business.workflowHandlers,
    });
    return {
      server,
      close: async () => {
        if (server.listening)
          await new Promise((resolve) => server.close(resolve));
        await business.close();
      },
    };
  } catch (error) {
    void business.close();
    throw error;
  }
}
if (
  process.argv[1] &&
  import.meta.url === pathToFileURL(path.resolve(process.argv[1])).href
) {
  requireThat(
    process.env.MODULE_PROJECTS_FILE && process.env.SERVICE_DATA_DIR,
    "service_config",
    "请配置 MODULE_PROJECTS_FILE 和 SERVICE_DATA_DIR。",
    500,
  );
  const directory = path.resolve(process.env.SERVICE_DATA_DIR);
  mkdirSync(directory, { recursive: true, mode: 0o700 });
  const projects = JSON.parse(
    readFileSync(path.resolve(process.env.MODULE_PROJECTS_FILE), "utf8"),
  );
  const service = createService({
    token: process.env.PLATFORM_SERVICE_TOKEN,
    callbackUrl: process.env.PLATFORM_ACCESS_DECISION_URL,
    filename: path.join(directory, "records.sqlite"),
    projects,
  });
  const port = Number(process.env.PORT || 0);
  requireThat(
    Number.isInteger(port) && port >= 0 && port <= 65535,
    "service_config",
    "PORT 无效。",
    500,
  );
  service.server.listen(port, "127.0.0.1", () =>
    console.log(
      JSON.stringify({ ready: true, port: service.server.address().port }),
    ),
  );
  for (const signal of ["SIGTERM", "SIGINT"])
    process.on(signal, () => void service.close().then(() => process.exit(0)));
}
```

```tsx
function useAction() {
  const [error, setError] = useState(""),
    [pending, setPending] = useState(false);
  const running = useRef(false);
  async function run(work: () => Promise<unknown>) {
    if (running.current) return;
    running.current = true;
    setPending(true);
    setError("");
    try {
      await work();
    } catch (reason) {
      setError(
        reason instanceof Error ? reason.message : "操作未完成，请重试。",
      );
    } finally {
      running.current = false;
      setPending(false);
    }
  }
  return { error, pending, run };
}
```

```markdown
# Node 模块 SDK v1

这是可随模块交付的服务端代码，要求 Node.js 24。生成器把本目录复制到生成包的 `sdk/node/`。不依赖 npm 安装，不导入主框架内部 Python，也不包含浏览器 SDK。

稳定边界：

| 接口 | 职责 |
| --- | --- |
| `createModuleServer({manifest, registration, token, handlers, workflowHandlers})` | 固定 HTTP 路径、恒定时间 Bearer 校验、64 KiB 输入、invoke 1.1 / workflow 1.0 包络、能力输入输出校验和安全错误；通过真实函数表分派 |
| `createRegistration(...)` | 启动时检查函数完整覆盖；握手时核对平台支持与完整声明后确认。不会调用业务函数 |
| `createAccessClient({callbackUrl, timeoutMs, fetchImpl})` | 向服务端配置的固定中央地址请求授权；票据缺失、超时、重定向、异常或无效回复均拒绝 |
| `Store.transaction(callback)` | 单连接串行任务及 SQLite 原子提交；业务对象和成功回执在同一事务中保存 |
| `Store.receipt/saveReceipt` | 请求编号绑定整个请求指纹，不包含传输头；重放前由业务重新授权 |
| `Store.cursor/offset` | HMAC 游标与调用人、授权修订、目录快照绑定；游标本身不授予权限 |

`invoke({body,ticket})` 返回 `{summary,data}`。`workflow({body,operation,ticket})` 返回适配器 `data`。`ticket` 只在当前内存调用栈使用，不返回、记录、写入仓储或传给前端。`facts` 必须来自服务端仓储；本 SDK 不会把输入自动变成可信事实。

`compile` 是明确封闭的 Schema 子集，支持本模板所需的 type、properties、required、布尔形式 additionalProperties、items、长度/数值范围、uniqueItems、pattern、enum、const 及说明字段。它不是完整 JSON Schema 引擎；Schema 形式的 additionalProperties、`$ref`、组合条件、format 等未支持内容在启动时拒绝。字段只按对象自身属性匹配，constructor、toString 和 __proto__ 不具有特殊验证能力。业务需要完整 Draft 2020-12 时，应以锁定版本的成熟验证库替换此适配点，并保留测试；不能静默忽略不认识的约束。

当前事务参考只面向一个 Node 进程和本地 SQLite。不要把持锁期间的中央回调扩展成长计算或外部写入；分布式副作用需要 outbox/inbox、领域幂等和恢复设计。本 SDK 不提供登录、角色引擎、游客、SSO、通知、长期委派、文件存储、长任务或聊天分支；这些能力不能通过添加同名配置字段声称实现。
```

```javascript
/** Trusted server-side client. Never import this into a browser bundle. */
export function createAccessClient({
  callbackUrl,
  timeoutMs = 4000,
  fetchImpl = globalThis.fetch,
}) {
  const endpoint = new URL(callbackUrl);
  if (
    !["http:", "https:"].includes(endpoint.protocol) ||
    endpoint.username ||
    endpoint.password ||
    endpoint.hash ||
    endpoint.search ||
    endpoint.pathname !== "/api/v1/access/remote-decisions"
  ) {
    throw new Error("Invalid configured access-decision endpoint");
  }
  if (!Number.isInteger(timeoutMs) || timeoutMs < 1 || timeoutMs > 10000) {
    throw new Error("Access decision timeout must be 1-10000 milliseconds");
  }
  // callbackUrl comes exclusively from deployment configuration. No URL, actor,
  // role, token destination or fetch options are accepted from invocation input.
  return async function decideAccess({
    ticket,
    requestId,
    operation,
    permission,
    facts,
  }) {
    const deny = (reason) => ({ allowed: false, reason, policy_revision: 0 });
    if (
      typeof ticket !== "string" ||
      ticket.length === 0 ||
      ticket.length > 12288
    )
      return deny("access_ticket_invalid");
    let body;
    try {
      body = JSON.stringify({
        request_id: requestId,
        operation,
        permission,
        facts,
      });
    } catch {
      return deny("access_decision_contract");
    }
    if (Buffer.byteLength(body, "utf8") > 16384)
      return deny("access_decision_size");
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), timeoutMs);
    try {
      const response = await fetchImpl(endpoint, {
        method: "POST",
        redirect: "error",
        signal: controller.signal,
        headers: {
          "Content-Type": "application/json",
          "X-Platform-Access": ticket,
        },
        body,
      });
      if (!response.ok) return deny("access_decision_unavailable");
      // Read bounded bytes rather than response.json() on an unbounded body.
      const reader = response.body.getReader();
      const chunks = [];
      let size = 0;
      while (true) {
        const { value, done } = await reader.read();
        if (done) break;
        size += value.byteLength;
        if (size > 4096) {
          await reader.cancel();
          return deny("access_decision_response_size");
        }
        chunks.push(Buffer.from(value));
      }
      const result = JSON.parse(Buffer.concat(chunks).toString("utf8"));
      if (
        typeof result.allowed !== "boolean" ||
        typeof result.reason !== "string" ||
        !Number.isInteger(result.policy_revision) ||
        result.policy_revision < 0 ||
        (result.allowed &&
          (result.reason !== "allowed" || result.policy_revision < 1))
      )
        return deny("access_decision_invalid");
      return {
        allowed: result.allowed,
        reason: result.reason,
        policy_revision: result.policy_revision,
      };
    } catch {
      return deny("access_decision_unavailable");
    } finally {
      clearTimeout(timer);
    }
  };
```

```javascript
/** SQLite unit of work: one connection, serial async operations, atomic business + receipt commit. */
import { DatabaseSync } from "node:sqlite";
import {
  createHash,
  randomBytes,
  createHmac,
  timingSafeEqual,
} from "node:crypto";
import { canonical, fail, requireThat } from "./runtime.mjs";

export class Store {
  constructor(filename) {
    this.db = new DatabaseSync(filename);
    this.db.exec(`PRAGMA journal_mode=WAL; PRAGMA busy_timeout=4000;
      CREATE TABLE IF NOT EXISTS kit_receipts(request_id TEXT PRIMARY KEY, fingerprint TEXT NOT NULL, object_id TEXT NOT NULL, response TEXT NOT NULL);
      CREATE TABLE IF NOT EXISTS kit_metadata(key TEXT PRIMARY KEY, value TEXT NOT NULL);`);
    this.db
      .prepare("INSERT OR IGNORE INTO kit_metadata(key,value) VALUES (?,?)")
      .run("cursor-key", randomBytes(32).toString("hex"));
    this.cursorKey = this.db
      .prepare("SELECT value FROM kit_metadata WHERE key=?")
      .get("cursor-key").value;
    this.queue = Promise.resolve();
  }
  transaction(callback) {
    const work = this.queue.then(async () => {
      this.db.exec("BEGIN IMMEDIATE");
      try {
        const result = await callback(this.db);
        this.db.exec("COMMIT");
        return result;
      } catch (error) {
        this.db.exec("ROLLBACK");
        throw error;
      }
    });
    this.queue = work.catch(() => {});
    return work;
  }
  fingerprint(request) {
    return createHash("sha256").update(canonical(request)).digest("hex");
  }
  receipt(request) {
    const saved = this.db
      .prepare("SELECT * FROM kit_receipts WHERE request_id=?")
      .get(request.request_id);
    if (saved)
      requireThat(
        saved.fingerprint === this.fingerprint(request),
        "idempotency_conflict",
        "同一请求编号的内容已经变化。",
        409,
      );
    return saved
      ? { objectId: saved.object_id, response: JSON.parse(saved.response) }
      : null;
  }
  saveReceipt(request, objectId, response) {
    this.db
      .prepare("INSERT INTO kit_receipts VALUES (?,?,?,?)")
      .run(
        request.request_id,
        this.fingerprint(request),
        objectId,
        JSON.stringify(response),
      );
  }
  cursor(binding, offset) {
    const payload = Buffer.from(canonical({ binding, offset })).toString(
      "base64url",
    );
    return `${payload}.${createHmac("sha256", this.cursorKey).update(payload).digest("base64url")}`;
  }
  offset(cursor, binding) {
    if (!cursor) return 0;
    try {
      const [payload, signature, extra] = cursor.split(".");
      const expected = Buffer.from(
        createHmac("sha256", this.cursorKey)
          .update(payload)
          .digest("base64url"),
      );
      const actual = Buffer.from(signature || "");
      if (
        extra ||
        expected.length !== actual.length ||
        !timingSafeEqual(actual, expected)
      )
        throw new Error();
      const decoded = JSON.parse(
        Buffer.from(payload, "base64url").toString("utf8"),
      );
      if (!Number.isSafeInteger(decoded.offset) || decoded.offset < 0)
        throw new Error();
      requireThat(
        canonical(decoded.binding) === canonical(binding),
        "revision_conflict",
        "目录或授权已变化，请从第一页重新读取。",
        409,
      );
      return decoded.offset;
    } catch (error) {
      if (error.code === "revision_conflict") throw error;
      throw fail("cursor_invalid", "分页游标无效。");
    }
  }
  async close() {
    await this.queue;
    this.db.close();
  }
}
```

````markdown
# Python 工具 SDK 1.0.0

已有 Python HTTP 服务另使用同目录 `registration.py` 主动核对注册握手，以及 `remote_access.py` 请求中央授权。注册确认器不替代 HTTP 认证或实际调用适配器，使用方法见同批 `docs/模块框架说明.md`。原生工具不进行远程握手。

稳定入口：

```python
run_tool(ctx, permission="your.module.use", payload=payload, handler=business_function)
require_organization_access(ctx, "your.module.use")

`ctx` 必须来自平台，提供认证后的 `actor` 与真实 `access.check(actor, permission, facts)`。本 SDK 只读取认证身份中的 `organization_id`，采用 `allowed is True` 默认拒绝，不包含 Casbin、角色回退或本地授权缓存。业务函数接收 JSON 对象，返回 `{"summary": "说明", "data": {...}}`；输入上限 100000 UTF-8 字节，结果上限 256000 字节。`ValueError` 映射为通用输入错误，其余业务异常交给平台安全错误处理。`KitError` 提供 code、message、status，由原生处理器转换成平台错误。
````

```python
    """
    actor = getattr(ctx, "actor", None)
    if (
        not isinstance(actor, dict)
        or not isinstance(actor.get("id"), str)
        or not actor["id"].strip()
        or actor.get("enabled") is False
    ):
        raise KitError("tool_identity_required", "需要有效的平台身份。", 403)
    organization_id = actor.get("organization_id")
    if (
        not isinstance(organization_id, str)
        or not organization_id.strip()
        or organization_id == "*"
    ):
        raise KitError("tool_organization_required", "请先由平台管理员分配所属机构。", 403)
    access = getattr(ctx, "access", None)
    if not callable(getattr(access, "check", None)):
        raise KitError("tool_access_unavailable", "平台权限服务不可用。", 503)
    facts = {"organization_id": organization_id}
    try:
        decision = access.check(actor, permission, facts)
    except Exception:
        # Do not expose provider errors or attempt a legacy-role fallback.
        raise KitError("tool_access_unavailable", "平台权限检查失败，请稍后重试。", 503) from None
    if not isinstance(decision, dict) or decision.get("allowed") is not True:
        raise KitError("tool_forbidden", "未获得本机构的工具使用授权。", 403)
    return facts


def run_tool(ctx, *, permission: str, payload: dict, handler) -> dict:
    """Check current scope and call a pure function returning summary + data.

    Platform input/output Schema validation, idempotency, CSRF, lifecycle and
    invocation history remain platform responsibilities. This wrapper neither

    """
    require_organization_access(ctx, permission)

        or not isinstance(result["data"], dict)
    ):
```

```python
"""Portable bilateral registration v1 for an existing Python HTTP adapter.

The adapter authenticates the connection before calling confirm. Handlers must
be the actual dispatch map, not a second list of claimed function names. This
module performs no business calls, database access or user authorization grants.
"""

from copy import deepcopy
import re
from types import MappingProxyType

from jsonschema import Draft202012Validator


class RegistrationError(ValueError):
    """Map to HTTP 422 with fixed wording, never echo a received contract."""


class Registration:
    def __init__(self, manifest, document, handlers, workflow_handlers=None):
        """Validate startup bindings and pin complete local declarations."""
        workflow_handlers = workflow_handlers or {}
        self._need(
            document.get("registration_version") == "1.0"
            and manifest["protocol_version"] in ("1.0", "1.1", "1.2")
        )
        self._need(
            (document["module_id"], document["module_version"])
            == (manifest["module"]["id"], manifest["module"]["version"])
        )
        self.ids = sorted(cap["id"] for cap in manifest["capabilities"])
        self._need(sorted(handlers) == self.ids and all(callable(fn) for fn in handlers.values()))
        self._need(
            sorted(workflow_handlers) == document["workflow_operations"]
            and all(callable(fn) for fn in workflow_handlers.values())
        )
        for cap in manifest["capabilities"]:
            for field in ("input_schema", "output_schema"):
                Draft202012Validator.check_schema(cap[field])
        self._manifest, self._document = deepcopy(manifest), deepcopy(document)
        self.handlers = MappingProxyType(dict(handlers))
        self.workflow_handlers = MappingProxyType(dict(workflow_handlers))

    @property
    def manifest(self):
        """Expose a copy, keeping the contract checked at startup immutable."""
        return deepcopy(self._manifest)

    @property
    def document(self):
        """Return the local public declaration without exposing mutable storage."""
        return deepcopy(self._document)

    @staticmethod
    def _need(condition):
        if not condition:
            raise RegistrationError("注册确认未通过，请检查协议、声明与接口绑定。")

    def confirm(self, offer):
        """Actively compare the platform offer, then acknowledge its unique nonce."""
        self._need(
            isinstance(offer, dict)
            and set(offer)
            == {
                "registration_version",
                "nonce",
                "contract_digest",
                "platform_features",
                "manifest",
                "registration",
            }
        )
        self._need(offer["registration_version"] == "1.0")
        for key, length in (("nonce", 32), ("contract_digest", 64)):
            self._need(
                isinstance(offer[key], str) and re.fullmatch("[0-9a-f]{%d}" % length, offer[key])
            )
        required = {
            "invoke-1.1" if self.manifest["protocol_version"] == "1.2" else "invoke-1.0",
            "shared-hosts-1.0",
            "registration-1.0",
        }
        if self.document["permissions"]["mode"] == "platform_access":
            required.add("access-1.0")
        self._need(
            isinstance(offer["platform_features"], list)
            and all(isinstance(value, str) for value in offer["platform_features"])
        )
        self._need(required.issubset(offer["platform_features"]))
        self._need(offer["manifest"] == self.manifest and offer["registration"] == self.document)
        return {
            "registration_version": "1.0",
            "nonce": offer["nonce"],
            "contract_digest": offer["contract_digest"],
            "accepted": True,
            "checks": {
                "platform_contract": True,
                "local_manifest": True,
                "local_registration": True,
                "handlers": True,
                "schemas": True,
            },
            "capability_ids": self.ids,
            "workflow_operations": self.document["workflow_operations"],
        }
```

### templates/module-kit/sdk/python/remote_access.py

```python
"""Portable access v1 client for trusted Python remote services (Python 3.11+).

Validate the incoming service Bearer first, read facts from your repository,
then call ``decide`` with the original request ID, operation and access ticket.
This client neither authenticates browser input nor replaces a state machine,
business revision checks or idempotency. Tickets must not be saved or logged.
Only httpx and the standard library are required; no platform imports occur.
"""

from __future__ import annotations

import asyncio
import hmac
import json
import math
import re
from urllib.parse import urlsplit

import httpx


_ENDPOINT = "/api/v1/access/remote-decisions"
_MAX_REQUEST = 16 * 1024
_MAX_TICKET = 12 * 1024
_MAX_RESPONSE = 4096
_IDENTIFIER = re.compile(r"[A-Za-z0-9][A-Za-z0-9._:-]{0,159}")
_FACT_KEY = re.compile(r"[a-z][a-z0-9_]{0,79}")
# Return public reason codes only, never arbitrary text supplied by a server.
# New central deny reasons remain denied as access_decision_invalid until this
# portable client's allowlist is updated; they cannot expand authorization.
_DENIAL_REASONS = frozenset(
    {
        "permission_unknown",
        "identity_inactive",
        "module_disabled",
        "policy_revision_changed",
        "required_fact_missing",
        "separation_of_duties",
        "actor_relation_mismatch",
        "fact_condition_failed",
        "grant_scope_mismatch",
        "command_unmapped",
        "access_ticket_invalid",
        "access_ticket_expired",
        "access_ticket_request_mismatch",
        "access_ticket_operation_mismatch",
        "access_decision_contract",
        "access_authorization_changed",
        "access_bridge_binding",
        "access_bridge_unavailable",
        "access_ticket_permission_mismatch",
        "actor_disabled",
        "authorization_changed",
        "capability_missing",
        "forbidden",
    }
)


def _deny(reason):
    return {"allowed": False, "reason": reason, "policy_revision": 0}


def service_bearer_matches(authorization: str | None, expected_token: str) -> bool:
    """Compare the configured service secret in constant time; never default open."""
    if not isinstance(authorization, str) or not isinstance(expected_token, str):
        return False
    if not expected_token or any(ord(c) < 33 or ord(c) > 126 for c in expected_token):
        return False
    scheme, separator, token = authorization.partition(" ")
    if scheme.lower() != "bearer" or separator != " " or not token:
        return False
    if any(ord(c) < 33 or ord(c) > 126 for c in token):
        return False
    return hmac.compare_digest(token.encode("ascii"), expected_token.encode("ascii"))


def _valid_request(request_id, operation, permission, facts):
    if not all(
        isinstance(v, str) and _IDENTIFIER.fullmatch(v) for v in (request_id, operation, permission)
    ):
        return False
    if not isinstance(facts, dict) or len(facts) > 32:
        return False
    for key, value in facts.items():
        if not isinstance(key, str) or not _FACT_KEY.fullmatch(key):
            return False
        if isinstance(value, str):
            if not 1 <= len(value) <= 160:
                return False
        elif isinstance(value, list):
            if not 1 <= len(value) <= 20 or not all(
                isinstance(v, str) and 1 <= len(v) <= 160 for v in value
            ):
                return False
            if len(set(value)) != len(value):
                return False
        else:
            return False
    return True


def _unique_object(pairs):
    result = {}
    for key, value in pairs:
        if key in result:
            raise ValueError("Duplicate JSON field")
        result[key] = value
    return result


def _invalid_constant(_value):
    raise ValueError("Non-finite JSON number")


class RemoteAccessClient:
    """Fixed deployment callback, bounded I/O and fail-closed central decisions.

    ``transport`` is the standard httpx test/transport seam. Each call closes its
    own HTTP client and never stores request facts or tickets on this instance.
    Caller cancellation propagates; operational failures return a safe denial.
    """

    def __init__(self, callback_url: str, *, timeout_seconds: float = 4.0, transport=None):
        try:
            if not isinstance(callback_url, str) or any(
                ord(c) < 33 or ord(c) == 127 for c in callback_url
            ):
                raise ValueError
            endpoint = urlsplit(callback_url)
            if (
                endpoint.scheme not in {"http", "https"}
                or not endpoint.hostname
                or endpoint.username is not None
                or endpoint.password is not None
                or endpoint.path != _ENDPOINT
                or "?" in callback_url
                or "#" in callback_url
                or (endpoint.port is not None and not 1 <= endpoint.port <= 65535)
            ):
                raise ValueError
            # Validate the actual HTTP library's URL parser as well.
            parsed = httpx.URL(callback_url)
            if parsed.raw_path != _ENDPOINT.encode("ascii") or not parsed.host:
                raise ValueError
        except (TypeError, ValueError, httpx.InvalidURL):
            raise ValueError("Invalid configured access-decision endpoint") from None
        if (
            type(timeout_seconds) not in (int, float)
            or not math.isfinite(timeout_seconds)
            or not 0 < timeout_seconds <= 10
        ):
            raise ValueError(
                "Access decision timeout must be greater than zero and at most 10 seconds"
            )
        self._callback_url = parsed
        self._timeout_seconds = float(timeout_seconds)
        self._transport = transport

    async def decide(self, *, ticket, request_id, operation, permission, facts) -> dict:
        if (
            not isinstance(ticket, str)
            or not 0 < len(ticket) <= _MAX_TICKET
            or any(ord(c) < 33 or ord(c) > 126 for c in ticket)
        ):
            return _deny("access_ticket_invalid")
        if not _valid_request(request_id, operation, permission, facts):
            return _deny("access_decision_contract")
        try:
            body = json.dumps(
                {
                    "request_id": request_id,
                    "operation": operation,
                    "permission": permission,
                    "facts": facts,
                },
                ensure_ascii=False,
                allow_nan=False,
                separators=(",", ":"),
            ).encode("utf-8")
        except (TypeError, ValueError, UnicodeError, RecursionError):
            return _deny("access_decision_contract")
        if len(body) > _MAX_REQUEST:
            return _deny("access_decision_size")
        try:
            # A total deadline also bounds custom transports and slow trickles.
            async with asyncio.timeout(self._timeout_seconds):
                async with httpx.AsyncClient(
                    transport=self._transport,
                    trust_env=False,
                    follow_redirects=False,
                    timeout=self._timeout_seconds,
                ) as client:
                    async with client.stream(
                        "POST",
                        self._callback_url,
                        content=body,
                        headers={
                            "Content-Type": "application/json",
                            "Accept-Encoding": "identity",
                            "X-Platform-Access": ticket,
                        },
                    ) as response:
                        if response.status_code != 200:
                            return _deny("access_decision_unavailable")
                        # Reject compressed bodies to avoid decompression expansion.
                        if (
                            response.headers.get("content-encoding", "identity").lower()
                            != "identity"
                        ):
                            return _deny("access_decision_invalid")
                        length = response.headers.get("content-length")
                        if length is not None and (
                            not length.isdigit() or int(length) > _MAX_RESPONSE
                        ):
                            return _deny("access_decision_response_size")
                        received = bytearray()
                        async for chunk in response.aiter_bytes():
                            if len(received) + len(chunk) > _MAX_RESPONSE:
                                return _deny("access_decision_response_size")
                            received.extend(chunk)
            result = json.loads(
                received.decode("utf-8"),
                object_pairs_hook=_unique_object,
                parse_constant=_invalid_constant,
            )
        except (ValueError, UnicodeError, RecursionError):
            return _deny("access_decision_invalid")
        except (httpx.HTTPError, OSError, TimeoutError):
            return _deny("access_decision_unavailable")
        if (
            not isinstance(result, dict)
            or set(result) != {"allowed", "reason", "policy_revision"}
            or type(result["allowed"]) is not bool
            or not isinstance(result["reason"], str)
            or type(result["policy_revision"]) is not int
            or result["policy_revision"] < 0
        ):
            return _deny("access_decision_invalid")
        if result["allowed"]:
            if result["reason"] != "allowed" or result["policy_revision"] < 1:
                return _deny("access_decision_invalid")
        elif result["reason"] not in _DENIAL_REASONS:
            return _deny("access_decision_invalid")
        return {key: result[key] for key in ("allowed", "reason", "policy_revision")}
```

## 通用架构、状态机与开发调试台

业务事实以模块返回的 projection.state 为准，个人流程 cursor 和任务 Run.status 分开处理。workflow 可以声明 state_machine；完整 Schema 随契约附录导出。它描述业务状态、转移及 step_id/action_id 引用，校验器检查重复、起点、端点与动作关系。guard_description 仅供说明，权限和状态守卫仍由模块后端执行；不得以浏览器改状态或模型文字代替业务事务。无状态机的历史流程显示未声明，不用导航步骤冒充状态。

模块开发完成后使用 /#devtools 检查 capability / interaction / workflow 的定义、引用版本、前端安装情况与可用性。JSON 校验不安装、不执行源码、不访问网络引用；在线交互 state_schema 正则不执行，含该类规则时到离线受控校验。调试台仅平台管理员可用，且只观察本人流程和当前有权业务对象；每2秒轮询、暂停/手动刷新、图与正式 FlowHost 并排。观察历史最多100条，仅当前对象的状态元数据，不含正文与草稿，也不是完整业务事件审计。源码已安装与浏览器构建已加载分别核实。

优先用 framework-lab 中立模块演练：创建→提交→退回→修改→重提→完成，页面/对话共用步骤组件和对象。它是本人调试样例，不是允许自审的真实审批规则。Node workflow-node 模板也从共享flow状态声明执行转移；其他模块可用自有业务状态引擎，仍返回统一投影。

架构与迁移入口见 docs/通用框架架构与代码地图.md、docs/模块开发与调试说明书.md、docs/框架迁移与AI交接指南.md。scripts/export_framework.py 从正向源码清单导出全新通用包，仅安装 framework-lab，重建提示词与说明书，不复制业务数据/凭据/远程连接/行业演示账号/依赖/构建物/Git历史。新包仍需安装锁定依赖、构建并实际验收；导出摘要不是运行验收。
# 模块接入验收同步

远程能力宿主使用 registration 1.0 双向验收。组件和流程本身仍由受控安装与生产构建加载；模块应在 host_requirements 声明实际需要的编号和版本，公开对象接口与真实分派表一致。主框架逐项校验声明、身份拒绝、健康、无效请求拒绝、模块主动确认和平台安装依赖，全部通过才能发布。权限附件先注册，实际用户授权另外管理。Schema 与两侧架构见同批 contracts/registration/v1、docs/主框架说明.md 和 docs/模块框架说明.md；业务组合、通用字段授权和业务正确性不由接入报告证明。
