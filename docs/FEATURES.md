# 主框架功能

## 模块、身份和公开能力

管理员维护服务连接，平台读取公开声明，逐项检查认证、健康、接口、模块确认及共享宿主依赖。七项通过后可显式发布。连接或声明变化清除旧结果，真实业务权限单独授予。

能力有稳定编号、版本、输入输出结构和两种入口。数据公开描述对象及可用操作；它不开放数据库直接写入。模块依据可信身份、实际对象事实和修订检查业务动作。

## 页面和对话

两种入口使用共同组件和后端。正式状态归业务模块；个人草稿、查看步骤与执行回执各自保存。本人可以在同一事项的页面与对话间继续，刷新重新读取当前正式对象。对话分支复制私有视图和引用，正式动作仍须实际执行。

## 图和观察

流程可以声明业务状态机。开发调试台展示已声明状态、动作、条件说明与真实对象状态，并分别列出导航和执行状态。观察每两秒重新读取，历史是有限快照，不能代替完整事件记录。未声明的流程明确显示缺项。

## 现阶段边界

组合业务是平台的发展方向。v0.01 提供公开描述与统一调用基础，通用多模块业务图、参数连接、自动执行及组合级恢复尚未实现。已实现与建议分别见 common-platform/docs/模块公开与业务组织分析.md。
